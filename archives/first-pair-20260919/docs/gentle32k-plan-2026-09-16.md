# K48两种子质量试验

目的：检查较温和稀疏能否在有限省时的情况下恢复长文本质量，而不是继续堆叠K32失败轨迹。

1. 完成两个内核、三个保留块数的正确性与端到端测速筛选。唯一合格的温和档位为M64/K48，三轮省时1.45%至3.51%。
2. 重放两颗种子的密集128步校准值，确认历史密集对照仍可复用。无新密集更新或重复任务预测。
3. K48完成梯度、因果性、断点恢复预检，然后使用原76个WikiText32K窗口、原两颗种子、原学习率计划分别训练128步；LoRA初始化与各自密集对照逐字节核验。
4. 固定128步后评价两个模型和一个零步稀疏基线。使用原64篇开发文章及原WikiText报告集，不把该轮当成独立确认。
5. 全量收集与审计后判断是否值得扩大。无自动延长，不把未显著下降报告为等价。

预设上限256科学更新、6诊断更新、576任务前向；阶段35分钟硬限制，每作业最长650秒。完整状态、校准值、计时、数据游标和原始预测均保存。

冻结协议：provenance/gentle32k-protocol.json。新训练与历史密集时间跨阶段比较只作成本估计，短测速提供同轮配对证据，不能忽略运行时波动。
