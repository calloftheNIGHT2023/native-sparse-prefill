# 本轮实验汇总：稀疏执行与从零学习

本固定19轮预算下，完整注意力通过，而精确QK top8从零训练未通过。已有完整模型改为top8仍保有高准确率，提示当前训练过程和可执行的稀疏表示之间存在差距；19轮不是充分调优后的能力上限。

## 到现在实际做了什么

前期4对KV任务中，多种方法接近100%，但固定保留源值位置也能成功，不能证明动态路由的独特价值。此前16对KV旧配置中完整注意力约7%，换新训练数据也未修复，所以当时不能用稀疏组失败推断其能力。

本轮先对齐Zoology作者配置，做两次完整注意力校准：lr0.0021544训练64轮失败，lr0.01第19轮开发99.9917%并通过新题/交换题。随后做三次已知稀疏配方的同初始化、同数据、同主更新预算比较，最后补一次精确主QK top8从零控制。合计6次正式训练，没有把技术测速当实验重复。

任务是约121万参数、2层单头模型，在序列开头的16对随机键值中，根据后文问题键找对应值。它是研究检索学习过程的合成控制，不是Qwen4或真实大模型训练。

## 两项0更新检查

第一项使用上一批独立新题seed2026091622，完整模型学会后冻结权重，再裁减聚合边：两层均用精确top8，新题99.7498%、交换99.8047%、噪声99.6582%。只裁第二层也单独保存。这里选位置仍扫描完整QK；结果只提供当前任务中少量聚合边可执行的权重例子，不能等同于从零稀疏训练成功。

第二项对fixed_values6递推两层计算图：约37.5427%的问题可以接触目标源值。另选1024个问题，交换两处不可达源值，标签改变而问题完整logits最大变化为0。这排除了“固定图其实通过两层偷偷读到全部源值”的实现疑虑。对理想均匀独立无放回源值可写出条件猜测上界1/(4096-m)，但这是固定计算依赖下的基本推论，不是新的ML理论，也不直接适用于学习选择器。

两项诊断所用测试集与本节五模型最终统一测试不同，不能逐条相减当配对效应。所有诊断0主/索引更新。

## 为什么现在还不够写成一篇有明确贡献的论文

1. **原创性尚未建立。** 公开任务、完整注意力、预热、选中集合KL、加性索引和精确topk均为已有机制；目前确认原创贡献数仍为0。
2. **解释还没被充分区分。** 同预算差距可能涉及学习速度、硬选择下的梯度覆盖、表示形成、dropout和优化参数适配。精确控制补上了一个缺口，但一次失败不能选定唯一原因。先密后稀能保留能力本身也不是新的方法主张。
3. **适用范围很窄。** 只有一个训练初始化、小型合成前缀查表任务，尚无跨种子稳定性、真实文本或长上下文训练证据。
4. **还没有经过强基线检验的新干预。** 需要先提出具体的新预测/方法，查清贡献边界，再看是否优于充分调优的已有配方。继续堆同类运行次数不会自动补上这一项。

本轮最有用的产出是建立可靠的阳性对照，并把“已学会后可以稀疏执行”和“从第一步稀疏能否在同预算学到”分开检验。它是进一步研究的依据，尚不是完整论文的证据链。
