# 下一步：把原文位置与文章难度分开

完整同卡曲线已核验：K32长题0/64/128步为18.75%/32.81%/32.81%；密集为50%/50%/45.31%；K48为25%/30.47%/32.03%。K32后64步没有净提升，差距收窄部分来自密集退步。原文与无原文输入长度不同，不能仅据两者准确率差断定模型没有利用原文。

因此先用已有128步模型做可控诊断，不继续相同配置训练。此前位置分组每组是不同文章，本轮让全部64篇文章都在10%、35%、65%、90%四个位置出现；每篇的题目、选项、答案、示例、无关背景顺序和32768-token总长度固定。四个位置是重复测量，不是四倍独立样本。

每个位置另生成等长替换条件：用该篇无关背景的固定token片段替换原文内容token，保留TARGET标记、问题和其余序列。它测试加入相关原文相对于同位置无关内容的作用；不是更换正确答案的语义反事实，也不自动证明注意力路由的因果作用。

固定密集和K32两种方法、各两颗现有种子、均128步。4个模型各512条长题，共2048次计分前向、0更新。每个模型包含64条与本轮4090原任务完全相同的输入，原选项logit必须在1e-6内重放；4段校准NLL仍使用1e-6阈值。K48已有成本收益较小，本轮机制对比预先固定密集/K32，不把排除K48后的结果当全方法比较。

主要统计是各位置原文存在减去等长替换的准确率变化，以及K32和密集的该变化之差；同时完整展示原文存在时的准确率差。按文章配对bootstrap，共同保留位置、条件和种子，报告所有位置及全位置平均，不选最有利位置。区间仅是旧开发集的描述性诊断，不是新的独立确认或非劣性检验。

总控制器上限4200秒，每模型1000秒；按本卡0.74美元/小时估算，这批GPU运行上限约0.86美元，另计准备和存储。失败不自动重跑、不放宽阈值。数据、4个固定模型引用与程序在启动前冻结SHA256，结果含逐题分数、UTC时间轴与失败归档。

预先确定的解释边界：若密集模型也没有稳定正的原文作用，先检查该任务测量是否适合；若密集能利用原文而K32明显较弱，再以完整配对差异设计机制干预。任何分支都不能将某个位置胜出直接写成论文贡献。
