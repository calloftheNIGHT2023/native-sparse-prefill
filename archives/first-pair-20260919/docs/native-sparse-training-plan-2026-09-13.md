# 原生稀疏训练讲解与首轮方案草案

2026-09-13。用户询问“原生稀疏训练是什么，他们怎么做的，我们怎么做”。本文件为设计说明，未实现、未运行；具体抽查改动未完成贡献查重。既有可行性来源见 `qsa-prefill-feasibility-2026-09-13.md`。

## 计算对象

训练阶段直接执行稀疏注意力前向与反向，让参数适应有限上下文连接。稀疏的是 query-key 连接，通常所有输入 token 仍保留；不是删掉90%的模型参数。索引器、压缩路径也有计算成本，不能以选中 token 占比代替总 FLOPs。native 不自动等于 step zero：允许从头模型采用短暂稠密预热，也可以从现成模型转换；必须明确训练日程。训练本身称并行因果语言建模，prefill 是推理时处理输入的阶段，两者共享相关算子而不是同一训练阶段。

## 前作机制

- NSA（https://arxiv.org/html/2502.11089v1，§3.3）：同时计算压缩信息、选中原始块和局部窗口三个分支，由门控融合。压缩分支直接参与预测，因此压缩参数有语言建模梯度；其注意力分数也用于选块。不是通过离散 top-k ID 本身反传。
- MoBA（https://arxiv.org/html/2502.13189v1，§2.2）：对块内 K 均值与 query 做点积，选相关块，加带因果掩码的当前块；Q/K 复用主注意力参数，没有独立新增索引器参数。Q/K 可以通过注意力计算训练，但选择 ID 仍不可微。
- QSA（https://arxiv.org/html/2608.30320v1，§2.1.2）：独立压缩索引器先全量蒸馏再联合稀疏 CPT，KL监督提供独立索引器的学习信号。
- MSA（https://arxiv.org/html/2606.13392v1，附录B）：直接比较索引器梯度来源、预热与辅助梯度detach，主配方仍有稠密预热。
- HiLS（https://arxiv.org/html/2607.02980v1，§3）：把块检索分数纳入前向输出加权，让LM loss训练检索分数。因此“给索引器LM梯度”已有先例。

## 我们要检验的假设

QSA 从零训练时，所选集合内的蒸馏监督是否缺少足够的集合外比较，从而延缓发现重要上下文？若成立，少量集合外抽查能否替代部分稠密预热？共享参数仍可能使未选块后续被选中，不能预先声称永久锁死。即使覆盖改善，也不保证冷启动主干提供的监督可靠或最终任务更好。

## 最小改动：增加索引器监督的比较范围

以示意预算为例（不是已选定超参数）：主分支每个query按QSA选择512个完整微块，记为 S。训练时，在满足因果约束、同一文档且未被选中的完整块中，均匀抽取32个块 E。稀疏主前向仍只读取 S 和原有尾块；对抽中的一部分 query，额外计算 S∪E 内主注意力分数，构造局部归一化块目标，训练索引器比较这些候选。未被抽查的query沿用原监督。

实施细节：主模型只接受 LM loss 的梯度；索引器输入 hidden states 和教师目标在辅助分支中 detach，沿用已有稳定化思路。主分支与索引器都在训练，detach 并非冻结整个主模型。主干 Q/K 在 E 上的额外评分不做反向，抽查分支不用 V 聚合；因果与文档掩码必须同时执行。不能把该子集 KL 写成全量 KL 的无偏估计，未做相应证明或采样校正。

推理 prefill 移除抽查支路，仍执行相同的 top-k 主注意力。这里仍有原版 QSA 的全候选轻量索引计算，不能宣称完全消除二次复杂度。训练增加的是少量主注意力候选评分和辅助监督，需要真实统计额外成本。

初版只用均匀抽查作为可解释诊断，不先叠加自适应采样、稀疏率调度、门控新结构。抽查本身不被认定为原创方法。后续若有效，再查相同机制、建立成本与收益的可靠关系。

## 首轮对照

使用约100M–300M参数的缩小语言模型，保留GDN/全局层混合比例和QSA选块机制；具体规模、token预算经短测吞吐再定。这是架构机制实验，不是原始Qwen4模型的全量复现。数据采用真实文本预训练，8K开始，32K作后续长度设置，分词器与文档划分一致。训练前固定校准/测试划分、随机种子与成本口径。

1. 混合主干的全局层全注意力：能力参照。
2. 第一阶段稠密、随后QSA：转换参照；计入转换前训练成本。
3. 短暂稠密预热后QSA：关键强基线。
4. 第一步QSA，只对选中块监督：直接提前启用的对照。
5. 第一步QSA，加集合外抽查：研究假设。
6. 原版QSA增加选择预算或训练量，匹配抽查总成本：排除“多花算力就更好”。

若观察到稳定差异，增加同混合主干下MoBA/HiLS等原生稀疏对照，以及纯注意力主干对照，判断是否为GDN混合特有现象。这个阶段必须在宣称新方法优势之前完成。

## 读出与停止条件

读出：验证/末段LM loss；多个长度的检索与证据组合准确率；诊断性抽样query全量注意力质量及漏选后重新选入时间；训练前向、反向、索引、辅助支路的耗时；prefill端到端延迟和峰值显存。注意力召回率只作诊断，不能代替任务正确率。诊断全量评分不得进入测试期训练更新，诊断成本单列。

如果第一步QSA没有稳定退化，则冷启动缺陷假设不成立，不制造方法需求。如果抽查只赢同token但输同成本的基线，不能宣称训练更高效。如果只改善选块指标而不改善长程任务，也不算目标成功。所有运行保存起止时间、配置、失败、tokens、设备、代码快照和日志；本文件没有任何新训练结果。
