# 下一步：用256篇新文章确认成本—质量折中

本轮只评测，不再训练。协议在任何新256题模型预测产生之前冻结；已有阶段结果用于设计这次验证，因此不是最初研究开始前的预注册。

## 固定模型与数据

- 父实验76窗口训练的密集/K32两个种子，均取固定128步终点，不挑最好断点。
- 加上密集/K32各一个零更新模型，始终保留基线；共6个模型。
- 256篇文章，逐篇排除本项目旧pilot/formal、32窗口64题、续训64题的文章哈希。
- 来源为固定版本RACE middle验证集213篇、测试集43篇。最初只考虑测试集，但按既有过滤和去重规则只剩48篇；在任何新题预测之前扩大到验证/测试集合并池，保留相同筛选规则。原方案未启动GPU，准备脚本与调整原因保留在logs。
- 每篇三个输入：短文、无原文、32K填充上下文。四种证据位置、四种正确选项各组合16篇；共768输入/模型、4608次任务计分前向。
- 此前未用于本项目评测，不代表原模型预训练时没见过；带TARGET标记的长文扩展也不属于官方RACE分数。

## 固定分析

先核验所有父检查点、原WikiText损失重放与校准重放，再检查新题逐个argmax、题目对齐和标签。

主要报告128步稀疏减密集的准确率差。每篇文章内先对两颗种子的差值取平均，再按文章配对bootstrap20000次，种子2026091696，报告95%百分位区间。两颗种子的预测不能当作512篇独立文章；这些区间也不涵盖广泛训练种子的不确定性。

没有根据成绩决定是否报告，没有事后选定等价容差；区间含0不代表证明相同。报告完整短文/无原文/长文成绩，以及长文减无原文成绩。如果长文不优于无原文，就不能用这组题证明长距离证据利用。

训练时间与PPL代价来自父实验，评测开销另列。新文章确认能加强题目层面的证据，不单独构成新方法贡献或跨模型泛化结论。
