# 相邻信息传递的定位对照

监督密度两组都未通过：测试38.96%/36.82%，多查询格式开发最后一题40.04%/38.48%。因此单纯增加监督未解决当前设置的键值绑定。本对照在新训练启动前固定。

只新增一个CPU运行，与recall-supervision-last-v0保持相同参数初始化、PCG64题流/变体、模型宽度/层数、4000步、3e-4学习率、最后一题监督。第一层注意力改为每个位置只能读取前一个位置（第0位置读自身），残差保留当前token；第二层仍为完整因果注意力。没有读取答案位置元数据，没有增加标签或输入答案。

目的：让记录的数值位置先接收相邻编号，再测试下一层能否按查询键找出数值。这是人为限制结构的诊断，不是普通完整注意力基线，不是新稀疏算法。第一层Q/K在单一可选位置下不需要学习选择；参数名义数量虽相同，有效训练自由度不同，不能解释为等容量方法比较或计算收益。

前驱复制及后续匹配的机制已有induction-head研究，本轮不主张原创。第二层仍访问全局，不能由此宣称全程高稀疏训练可行。

固定4000步最终开发/测试均80%门槛，CPU墙钟最多900秒，不延长。开发集再做只替换查询键的干预；若通过，只表示这一受限结构在当前任务上可学，后续另核实普通注意力如何形成相同能力。既有失败继续保留。前驱掩码与外部局部对照掩码取交集，不允许访问未来，不支持decode/cache。
