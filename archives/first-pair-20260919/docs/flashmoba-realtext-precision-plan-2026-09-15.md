# 均值精度：真实文本上的有限验证

问题：官方低精度块均值有选块变化，但它对模型输出的影响是否足以支持继续研究？普通局部 FP32 已有 Switch Transformer 等先例，本实验不申报它为原创方法。

使用已固定 SHA 的 Pythia-70m-deduped 最终检查点，16段不重叠的 WikiText-2 test token窗口；长度1024/2048为同一窗口的前缀，不能算32段独立样本。材料仍来自此前用过的测试语料，不声称与预训练去重或新的最终盲测。

五种条件：Flash稠密；B128 K2/K4官方均值；同一B128 K2/K4改为FP32累加、再转回BF16均值。QKV、模型权重、路由点积和注意力CUDA核保持一致。替换全部6层，冻结模型、不训练。初次检查适配器与完整官方调用一致、全块模式接近Flash、同输入重复调用无差异。

记录每段token NLL、argmax、相对稠密结果，另在前4段/每层的相同QKV上比较选块与注意力输出。以段为单位对“FP32池化减官方池化”的NLL差异做固定seed配对bootstrap；不能把数万个token当独立样本。前半上下文几乎不稀疏，因此同时报告后半段NLL。

扩大门槛提前固定：2048长度下两个K均有绝对平均NLL差大于0.01 nat/token，且95%区间不跨0，才考虑把精度问题扩到更大模型/训练；方向、改善或恶化分别报告。未达到则暂停精度单独立题。大量路由变化不自动等于模型变好。

成本限于这次模型评估，0优化器更新。不是原生稀疏训练结论，也不把随机QKV的32K速度表搬成此模型的训练性能。
