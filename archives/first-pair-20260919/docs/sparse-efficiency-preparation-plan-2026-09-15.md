# 同等效果下的效率验证：本地准备

记录日期为 UTC 2026-09-15；用户当地日期仍为 2026-09-14。

## 决策修正

用户明确接受效果相近的贡献，不要求准确率超过最新方法。此前反证只否定“这个任务上的稀疏学习失败必须引入新修复机制”的解释，不能据此关闭整个原生稀疏训练方向。准确率基本持平已在一个小型 MQAR 配置上出现；效率、真实文本泛化与原创性仍待证实。

旧报告、原始预测、检查点以及 348 文件的最终归档保留原样。此文是后续决策记录，不追改历史结论和归档哈希。

## 本轮范围与支出

- 只用本地 CPU 准备和验证，不新建云资源、不开始科学训练，新增科学优化步为 0。
- 全部仍在原 500 美元总预算范围内；既往实际账单未知，不能把它当作剩余 500 美元。
- 实现同一 2 个局部位置 + 6 个内容位置的因果选择规则；分块计算精确候选分数，仅保存索引，在选中边上汇总和反向传播。
- 精确全局选点仍需二次数量级打分；本实现不声称线性时间，不声称是新的稀疏算法，也不是融合 Triton/CUDA kernel。
- 首先核对算子输出、Q/K/V 梯度、因果边界、重复索引梯度累加和 dropout 的反向传播；再重放既有冻结检查点的已暴露测试集。这是实现迁移检查，不是新的泛化证据。

## 预先指定的验证

1. FP64 随机输入：与原完整矩阵掩码实现对照输出和梯度；包含短序列、多个头、非整块尾部、局部窗口、k 覆盖全序列。
2. 有限差分 gradcheck；保存张量检查确认反向不保存 N×N 注意力矩阵；自定义反向只支持一阶梯度。
3. 使用固定紧凑 dropout 掩码与普通自动微分参考对照。紧凑随机数布局不同于旧 N×N 布局，不承诺逐步训练轨迹相同。
4. 原生低学习率 seed123、124 的最终冻结检查点，重放统一新题、交换答案、噪声三组已暴露测试；先冻结文件 SHA，不根据测试选参数或轮次。预计比较 67,584 个答案。
5. CPU 计时仅用于验证计时脚本和找明显实现瓶颈，不能推断 A40 加速。GPU 脚本必须包含选点的总成本、预热、同步、逐次原始计时、峰值显存、设备与源码信息。
6. 同时比较旧掩码 top-k、分块 top-k、完整注意力 SDPA；GPU 时额外强制 FlashAttention 后端，若不支持就明确标记，不能静默降级后仍称 FlashAttention。小算子耗时不得称整个模型训练耗时。

- Gupta 等，Memory-efficient Transformers via Top-k Attention，SustaiNLP 2021：[论文](https://aclanthology.org/2021.sustainlp-1.5/)、[原文](https://aclanthology.org/2021.sustainlp-1.5.pdf)。已核查摘要与方法相关内容；查询分块、精确 top-k、缓存稀疏信息并重计算属于已有思路。本轮是适配我们的因果算子的工程基线，不以此申报原创。
