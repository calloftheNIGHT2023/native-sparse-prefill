# BabyLM 上的第一阶段稀疏预训练：补救设计 v0

2026-09-17。用户明确允许更换为 BabyLM。本文接续 original-objective-repair-2026-09-17.md，优先于旧 LoRA/CPT 实验和其自动队列。状态：数据准备与设计，不是已启动或已冻结全部超参数的科学实验。

## 1. 保留问题，收缩结论范围

主问题：在有限训练数据下，从随机初始化开始进行全参数语言建模，学习式稀疏注意力能否从第一步使用，以更低的实际训练成本获得接近密集对照的语言能力？如果直接做不到，障碍来自哪里，能否在不先做密集主干预训练的前提下解决？

BabyLM 是数据与评测体系，不是一种模型。更换数据不自动要求丢弃 GDN/QSA，也不使旧 LoRA 结果变得可外推。研究主张先限定为“小规模、数据受限的从头预训练”；未经额外验证，不宣称适用于完整 Qwen4、大模型 scaling law 或 256K 训练。原 Qwen 架构与训练报告说明 QSA 在后期 CPT 引入，并没有证明它必然不能冷启动。

已撤销：用预训练模型 LoRA、换成预训练模型全参数 CPT、扩大人工检索题数量来回答原题。历史证据保持原样，仅保留可重新验证的工程设施。

## 2. 数据和训练量

官方 2026 Strict-small：语料不超过 10M 个空白分隔词，累计输入暴露不超过 100M 词。Strict：语料不超过 100M 词，累计暴露不超过 1B 词。上限不是必须达到的最低数值，也不是 subword token 数。采用纯文本自回归学习，不调用外部预训练教师，不加载预训练权重或外部 tokenizer。

第一轮使用 Strict-small，目标完整训练上限为 100M 词暴露；不是跑几百步即宣布成功。模型规模先以约 80M–120M 参数为工程候选，实际构建计数后再锁定。若只能跑更小模型，明确标为筛查。Strict 100M 词作为第二数据规模候选，只有第一个完整对照、吞吐和账单支持时再启动。

2026-09-17 已下载并核验官方 Strict-small 的六个文件：总计 54,399,840 字节，恰好 10,000,000 个空白分隔词。版本 c92ab16b4f08858304b0815706065b3354d8fc0a。见 data/babylm-2026-strict-small-raw-v0/manifest.json。尚未训练 tokenizer 或模型。

数据工程必须分别记录：原始语料词数、每轮读取词数、累计暴露词数、非 padding token 数、参与 loss 的 token 数、截断/重叠重复输入。相同数据顺序和掩码用于配对组。仅用训练集训练 BPE（16K 词表为候选），开发集只做固定限额调参，最终评测不参与选择。若扩展到 Strict，先验证子集关系及 tokenizer 控制策略。

当前文本记录较短：六个文件均无单行达到 2048 词；Gutenberg 最长一行 1033 词。行不等于文档，不能据此声称没有长文，也不能把不相关行拼接成 8K/32K 后声称存在相应长程依赖。下一步追踪官方预处理的文档边界和顺序，锁定分隔/packing 规则，并在固定开发集比较 dense 的不同可见上下文收益。若真实远程信息不足，BabyLM 只用于语言学习和优化问题，不用于证明长上下文检索优势。

## 3. 模型与实现边界

主候选保留 GDN 与全局注意力层 3:1 的混合结构，以及独立 QSA 索引器；暂按 12 层、宽度 768、dense FFN 进行容量/算子可行性核查。此处明确不复现完整 MoE/PLE 等系统，名称为“小型 GDN/QSA 混合研究模型”，不得称完整 Qwen4。GR 等其余差异必须在架构对应表逐项列出。纯 Transformer 只可作为独立控制，不能静默替代混合主实验。

共同主干参数在每个配对种子下逐 tensor 相同；索引器使用单独 RNG 流，防止其初始化改变主干随机数序列。embedding、GDN、attention、FFN、norm 和输出层均可训练。Late 的预定短索引器预热是唯一额外主干冻结阶段，须明确记录。

QSA 必须按原来源核验微块平均池化、块位置 RoPE、ReLU 头聚合、因果可见完整块与尾块、独立索引器、teacher 聚合/归一化/KL 与 detach。主损失通过硬 top-k 索引不会自动为离散选择提供有效梯度，Early 的索引器需有明确可工作的辅助学习目标。直接移除公开 warmup、从步 0 使用 selected-support KL 是基线假设，不是已被证明的新方法。

默认工程上下文候选 2048，微块 4、最多 64 个完整历史块加因果尾部为初始预算候选；最终取值在检查文本有效长度及吞吐后、读科学结果前冻结。对短前缀自然全可见，逐 query 记录实际保留比例；不能用 2K 长度配 2048-token 预算却报告稀疏。辅助全支持诊断仅在预定少量样本上、无优化器更新地执行，其开销另记。

主训练前必须验证：所有预期参数梯度/更新覆盖，主干与 indexer 的梯度来源，未来信息不泄露，文档 mask 正确，固定路由下稀疏前向和反向对 dense-masked reference 数值一致，恢复优化器/RNG/数据游标一致。reference 计算完整 QK 或 dense mask 只能用于数值验证，不能作为省算实现。旧 FlashMoBA 不可改名 QSA。

## 4. 最小实验链

|组别|从零开始的完整训练轨迹|用途|
|D|全局层始终 dense，GDN/FFN 等共同组件相同|质量、学习曲线及成本基准|
|E|全局层从第一个优化步起使用 QSA；无预训练主干/教师|直接回答第一阶段稀疏是否可学|
|L|从相同随机主干先 dense，预定阶段训练索引器，再切 QSA|对照“为什么需要晚转换”；所有前期代价计入|
|W|从步 0 使用匹配可见预算的局部窗口，无学习式索引器|判断是否根本不需要学习式远程选择|

先 D/E 通过技术门槛和完整单种子筛查，再补 L/W；筛查种子不当作独立确认。L 的候选 80% dense、2% 冻结主干训练索引器、18% sparse 都计入总词暴露，正式运行前根据实现验证锁定，不根据最终结果找最优切换点。它只是本研究的缩小转换配方，不能称官方比例复现。另报各组主干实际更新量，不能隐藏 L 的冻结差异。

确认阶段关键比较目标为至少 3 个独立配对训练种子；所有主结果保留，不挑最好的 checkpoint 或 seed。若预算不够全部条件的确认，不把题目级 bootstrap 冒充训练重复，也不声称主张已确认。D/E/L 初始超参搜索预算对称；学习率日程按各自预先规定训练终点设置，同样步数并不必然公平，同样 tokens 也不等于同样计算量。

不预先假定一定需要一个新方法。只有 E 显著落后且实现/训练配方排除错误后，才做小规模诊断：索引器监督是否过时、是否缺少集合外比较、注意力尾部是否承载有效信息、GDN 与全局层是否尚未形成分工。一次干预对应一个可证伪解释。任何修复候选先对照 NSA、MoBA、MSA、HiLS 等原文查重，不能把 warmup、detach、LM 梯度、采样或密度日程本身称首创。

## 5. 成功标准：同等质量下更省成本

需要同时提供三种视角：相同词/token 暴露的质量；相同总 GPU 时间/费用的质量；达到固定质量目标的成本。主评测为固定开发/测试文本 NLL 与官方 BabyLM 语言评测，完整报告分任务得分。BLiMP/Entity Tracking 等以官方概率打分方式评估，避免依赖随机初始化小模型尚未习得的指令遵循能力。fast 与 full 按官方用途区分；不把 fast 子集写成完整评测。

等价/非劣界限须依据新指标的实际意义，在确认实验前写死，不能继承旧检索 5pp 或看到 CI 后定线。给定预算与种子数若不能排除有意义的退化，结论只能是证据不足。设计不要求 sparse 胜过 dense，但“统计不显著”也不等于“已经一样好”。

计时包含索引器、top-k、辅助 loss、全部前后向、优化器、数据装载、compile/warmup、验证/保存；分别提供训练主体和完整作业总账。L 前期 dense 及教师计算不免单。训练失败、调参、诊断、存储另列为研究总成本。最终模型还需保持它实际训练和声称使用的注意力方式，不以切回 dense 后的结果掩盖失败。

理论稀疏比例不能保证实际加速。若注意力占原始总时间 f，注意力部分加速 s 倍、额外开销折算为原总时间 a，则总加速近似 1/[(1-f)+f/s+a]。只作为结构性分析，f/s/a 必须实测。GDN 占 3/4 层且 BabyLM 上下文短时，可能收益很小；不能为制造省时改用不优化的 dense 对照或把无关短句强拼成长文后不披露。

## 6. 决策与论文边界

- E 质量接近 D 且真正更便宜：再验证种子、数据规模、密度/长度适用范围与原生稀疏强基线；这是候选证据，不直接等于原创贡献。
- E 不如 D，但局部 W 也不如：区分注意力信息容量不足和索引器训练问题；不能直接归因于 cold start。
- W 与 E 一样好甚至更好：当前数据可能不需要学习式远程检索；不靠加入更多简单题继续包装 QSA 收益。
- E 质量好但总成本没有优势：报告其可学习性，不能宣称节省预训练成本；检查真实更长文档是否能提供新信息，条件不成立则停止这条成本假设。
- 一项修复在相同预算下稳定优于 E/L，并有机制消融及新颖性边界：才有方法论文候选。用 BabyLM、用小模型、从头训练本身都不是新贡献。

BabyLM 研究的是明确的数据受限情形。Chinchilla 类计算最优关系不是预训练实验的准入线；但不能因此宣称我们的配置是计算最优，或从一个小点外推大模型 scaling。预算优先用于完整轨迹和独立种子；第二模型/数据规模应围绕确切外推主张，而非盲目扩大。
