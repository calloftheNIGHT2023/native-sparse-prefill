# KV16完整注意力的新题流诊断

这是在固定训练集80轮对照失败之后单独登记的诊断，不是原压力批次的续训或事前假设。原批次结论与三组跳过状态保留。

问题：旧对照训练准确率42.69%、新题7.16%，96.32%预测在16个源值中，显示没有良好学会键值对应。每轮重复同一万条题是否阻碍泛化？只把每轮训练题换新，保持主干、初始化、优化器、dropout、每轮样本数、总80轮与25040步/102400000输入tokens不变。

仅一项dense新训练。从原pressure initialization.pt的主干初始化，不从失败终点接续。单头2层128宽445952参数。每轮10000条KV16/长度128；相同已存开发集用于观察，不提前停止。AdamW lr0.001、wd0.1，cosine T_max100；每轮313步（312批32＋最后16）。没有索引器、KL或稀疏性。80轮完成后才评测。单次20分钟上限；整批25分钟保护。

第1至80轮训练数据seed=2026091500+轮数，由固定版本MQAR生成。生成时临时设置CPU Torch/NumPy RNG并恢复，避免改变dropout随机流。新开发和测试不参与训练；新的最终测试1024条seed2026091591，16答案/条，源值交换1024题。新测试用于本诊断与旧dense80权重共同评测，旧终点无新增优化步。沿用99%双门槛，只判断新题流是否建立有效完整对照。

每个训练epoch保留压缩inputs/labels、种子和张量哈希，检查标签以及与所有旧分割、新测试及先前epoch无整行重复。保存逐步损失/梯度/用时/计数、每轮开发指标、原子最终checkpoint和20/40/80轮节点、RNG/优化器/调度器、源码、冻结计划、环境及清单。

本机事后核验SHA、连续步数、GPU预测，复核40/80轮节点的新题表现只作诊断，不据测试选checkpoint。新数据量是800000个独立序列对旧10000条，累计训练样本暴露相同；这是数据重复策略改变的探索性实验，不能称为严格控制所有数据因素，更不能作为新算法贡献。

若失败，不启动稀疏对照，不增加总轮数或改成功门槛。若成功，只建立后续比较的训练设置，另行登记稀疏配方的匹配预算。沿用现有A40，未租新卡，总500美元及首阶段30美元边界不变，累计账单未知。报告必须保留前次负结果和这一探索性来源。
