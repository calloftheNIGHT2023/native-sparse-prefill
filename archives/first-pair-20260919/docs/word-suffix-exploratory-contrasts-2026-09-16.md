# 后缀实验的训练方式交互：探索性补充

原始审计：results/word-suffix-audit-v0/result.json。此处是在看到结果后计算的探索性对照，未新增GPU前向，不冒充预注册主检验。

- 稀疏训练+密集后缀与密集训练+全密集：-7.8125pp，32背景组配对95%区间[-19.53125,3.90625]。
- 同用稀疏前缀+密集后缀时，稀疏训练与密集训练：+7.03125pp，区间[-8.59375,21.875]。
- 训练方式与评测方式（SD相对DD）的交互：+17.96875pp，区间[4.6875,32.03125]。

这提示继续训练可能改变模型对前缀计算方式的适应，而只把所有注意力切回密集未必是合适对照；但32背景、2种子及单一词值任务不够支持泛化主张。尤其第一项区间很宽，不能因为含0就宣称等价。下一步先完成真实整模型成本核验，再安排固定的新数据检验，不依据新结果随意扩大可接受误差。
