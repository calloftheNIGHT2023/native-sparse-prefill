# 这次配置敏感性对应什么数学问题

以下是标准浮点误差和top-k扰动的解释，不计本项目原创定理。实测范围见本轮报告；没有证明训练效果或所有输入上的位级一致性。

设块内有B个key，均值为 μ_b=(1/B)Σ_j k_j，路由分数为 s_b=qᵀμ_b。官方实现把块分成大小R的内部归约组，R就是kBlockN。内部tl.sum保留输入浮点类型，随后加进FP32累加器，最终仍写回BF16。

因此三种R对应同一个实数公式，却不是同一条浮点计算路径。可以概写为：

μ̂_b(R)=round_BF16[(1/B)·sum_FP32_g(sum_BF16_{j∈g} k_j)]。

若把内层输入先转成FP32，内外求和都在FP32完成，最后仍有一次BF16舍入。该修改减少配置变化引入的误差，但不自动保证任意输入、任意配置都产生相同的BF16值。

在无溢出、忽略次正规数等通常假设下，n项浮点求和的保守界使用γ_(n−1)=(n−1)u/[1−(n−1)u]，乘以各项绝对值之和，其中u是该格式的单位舍入误差。实际树形归约通常可给更紧界，但需要知道生成代码的归约深度；这里不把未检查的归约树当已证明。BF16的u=2^-8，FP32的u=2^-24。分组变化会改变低精度舍入发生在哪一步。

令池化误差为 e_b=μ̂_b−μ_b；固定q时，仅池化引入的分数误差满足：

|qᵀe_b| ≤ ||q||₁ ||e_b||∞。

如同时分析点积舍入，还要另外加入点积误差，不能把它省去。设所有候选块的总分数误差都不超过ε。排除强制保留的当前块后，若第K−1个和第K个远端块的真实分数差Δ>2ε，远端top-(K−1)集合就保持不变。证明是：任一被保留块与未保留块的分差，最坏只缩小2ε。存在并列时不满足严格条件。

当Δ≤2ε时，不能保证集合不变，但也不能断言一定改变。选块一旦变化，随后参与softmax的是不同key/value集合；小的路由分数误差不单独约束被换入/换出value造成的输出差。因此不能由“平均NLL几乎相同”推出逐位置预测一致。

本轮实验支持的是这条机制的实例：固定真实QKV，更换求和配置改变路由；固定配置自身重复可复现；固定完整模型和文本，更换R改变很多下一词argmax，而平均NLL仍接近。要把它发展成论文，还需要超出这一标准解释的贡献，并与[已有推理可复现性工作](https://thinkingmachines.ai/blog/defeating-nondeterminism-in-llm-inference/)区分。
