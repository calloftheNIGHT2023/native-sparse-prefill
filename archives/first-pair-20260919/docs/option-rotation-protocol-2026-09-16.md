# 固定四种选项轮换：检查字母偏置与内容判断

前一批2048次原文替换诊断已完整核验。四个位置平均，密集的原文作用为+1.17pp（文章配对95%区间[-4.30,+6.84]），K32为+0.59pp（[-1.56,+2.73]）；不能把整个长题分差归因为相关原文未被读取。原文存在时，两个种子的K32分别158/256、147/256次选C；密集分别109/256、114/256次选C，正确字母始终均衡。频率偏斜本身不证明全部分差来自字母偏置。

下一项仅改选项排列：每篇原题用四种循环排列，使每个答案内容在A/B/C/D都出现一次。全部64篇，不依据预测筛题；固定密集/K32各两颗128步种子。短原文与原32K长输入各评测一遍，共4模型×64篇×4排列×2长度=2048次计分前向，0训练更新。

严格保留示例、原文、背景、问题与各答案内容；tokenizer逐例断言选项循环排列后的suffix长度不变，整段长度、原文位置和背景token完全不变。每个模型的64条原顺序32K输入与同4090已核验结果在1e-6内重放；4段校准NLL门槛不变。

固定报告原顺序准确率、四种顺序等权平均准确率、两者的稀疏减密集差值及差值变化、语义答案在四种顺序上的一致率、原始字母频率。统计按64篇文章配对bootstrap，保留全部排列、长度和种子。不给模型拟合校准器，不挑最好顺序，不用多排列集成包装成单次推理质量。它仍是旧开发集诊断，不能证明独立泛化或非劣性。

控制器上限2400秒、每模型550秒，本卡0.74美元/小时，实验GPU运行上限约0.49美元，不含准备、空闲和存储。失败保留原日志，不自动重跑。

相关工作已做边界检查，以下为2026-09-16查阅的原始出版页摘要范围，不声称完整复现其方法：

- [Pezeshkpour and Hruschka, NAACL Findings2024](https://aclanthology.org/2024.findings-naacl.130/)：已经研究多选题的选项顺序敏感性与校准。轮换选项本身不是新方法。
- [Wei et al., ACL Findings2024](https://aclanthology.org/2024.findings-acl.333/)：已研究选择顺序和选项token的偏置及缓解。不能把发现C偏置当原创贡献。
- [Zhao et al., ICML2021](https://proceedings.mlr.press/v139/zhao21c.html)：已有上下文校准研究。后续若尝试校准，必须计入已有方法并用独立数据，不能调到当前题分最高再宣称稀疏等价。

若轮换后稀疏差距仍在，保留该负证据；若差距明显变化，只能说明原先指标受排列影响，仍需另一个能有效利用上下文的任务和真实成本测量。较早的自建四记录检索任务在短输入能力检查已失败（4/32），不直接重复它作为新能力证明。
