# 用户最新顺序：先测 step-zero sparse 的差距，再研究解决方法

2026-09-17。本文件依据用户最新指令，优先于此前“先修复/先扩展对照”的安排。

## 当前只回答一个问题

随机初始化、全参数训练，在相同主干初始权重、训练数据顺序和输入/损失掩码下，直接从第一个优化步骤使用 QSA，会不会比密集训练学得更差？这里先建立一个有效基线结果，不预设一定有 gap，也不预设 gap 的原因。

第一批仅两组：D（全局层始终 dense）与 E（全局层自 step 0 稀疏，按已声明的 selected-support 辅助目标训练随机 indexer）。共同主干全参数训练；不加载预训练权重、LoRA、外部教师，不加密集预热、额外采样、密度课程、QK恢复等修复。普通优化器学习率 warmup 与密集注意力 warmup 是不同事情，前者可按共同训练配方使用。

L（后期转换）、W（局部窗口）与任何新方法暂不排入首批；只有 D/E 结果提供对应需要时才追加。基本错误检查与来源记账继续，但不能无限扩展成先做完整系统再观察第一个科学结果。

## 最短有效开工路径

1. 实现独立 tiny GDN/QSA 混合模型，检查全参数可训练、共同权重/RNG、正确因果路由、GDN状态边界、选满支持时与dense一致、检查点恢复；tiny只作工程验证。
2. 科学数据采用固定官方训练流和明确的packing规则；两组完全相同。已有文件和显式文档标记作为已知重置点，隐藏抽样断点记录为未知。不得跨文件或已知标记拼接，不把未知连续性声明为自然长文连续性。**完整恢复所有PG/CHILDES原文不是首个BabyLM语言学习对照的前置条件。** 来源小样本对齐可并行有界进行；“自然长程检索”结论仍须独立连续性证据。
3. 实际输入须含非平凡稀疏查询，记录逐token支持密度；逐行隔离94%保留率不作为目标主设置。设置固定训练窗口不意味着窗口具有同长度真实语义依赖，这个限制在结果里保留。
4. 两组完成一次预算内可承担的预注册训练轨迹；目标仍是Strict-small最多100M词暴露的完整实验，而不是根据早期几百步分数宣布科学结果。若当前预算只能完成早期轨迹，必须标为筛查并同时保留两组。
5. 首个单种子差距是探索信号；确认有稳定gap再进入机制诊断与修复。同数据同种子的随机权重/顺序配对不能代替独立训练种子确认。

## 质量优先的实现门槛

首个gap实验需要**数值正确的训练实现**，不要求先开发出最优稀疏GPU内核。若正确的mask/gather reference能在已批准成本上限内完成小规模D/E筛查，可以用于质量可学习性比较；但必须明确它不证明稀疏训练的实际加速，更不能将其慢速当作高效实现不存在的证据。

付费工作仍需要正确反向、可完成的两组预算、冻结数据/配置和云连接；不因用户强调先测gap而豁免预算。无需为首次质量筛查先完成所有高性能内核优化、全部文献扩展、L/W或多尺度矩阵。

## 首份结果应包含什么

- 相同有效训练暴露下的开发集NLL差 `E - D`，以及两条完整学习曲线。
- 固定BabyLM语言评测的分项分数，不用旧人工检索任务替代。
- 实际支持保留率、主干/indexer梯度与更新计数、异常/失败、输入词/token/loss计数。
- 两组真实耗时和费用，包括辅助目标；参考实现计时只说明本次作业成本，不用于宣称方法加速。
- 区分早期学习变慢、最终仍有差距、训练不足/不稳定或指标不确定。不能只拿一个checkpoint给差距下定义。

判断：E稳定更差，排除实现错误和明显配方不公后，定位gap并研究修复；E已接近D，则不制造修复问题，转而检查非劣质量下是否真能省成本；结果不确定时优先补足配对训练/独立种子，不能凭“没有显著差异”称等价。微型CPU测试不能充当该科学结果。
