# 固定权重切换注意力：事后机制诊断

触发：已冻结的96题RACE-M扩充上下文评测显示，短题平均准确率dense63.02%、K16 65.10%，8K为51.04%/40.63%，16K为45.83%/34.90%。prefill也未加速。不能据此区分参数训练带来的影响和评测时注意力路由带来的影响。

保持四个最终LoRA断点、同一题、同一提示、同一选项和评分方式，仅切换评测时注意力：dense训练权重改用K16评测；K16训练权重改用dense评测，各两个种子。原来的dense/dense和K16/K16结果保留，组成2×2表。每个模型先在原模式通过校准NLL重放≤1e-6，之后才切换模式。没有任何权重更新，不重训，不改变K或选择学习率。

这是看到正式题结果后设立的事后机制诊断，不能称为新保留验证，也不能择优汇报。四项均报告，按短/无原文/8K/16K、证据深度及两个种子分开。重要比较为K16训练+dense评测对dense训练+dense评测，及同一K16权重切换前后的差别。若变好，只能说明此设置下训练与使用注意力应分开考察；若不变或变差，也照实记录。不能由该干预直接推断唯一的内部机制。

当前只运行此前通过能力检查的阅读理解任务。检索仍不达标，不借机修改检索模板或题目。所有结果只是0.5B LoRA、96题改造版、同语料提示形式、两个共享训练顺序种子的局部证据。继续沿用5pp描述性容忍范围，不能因没有显著差异而宣称等价。
