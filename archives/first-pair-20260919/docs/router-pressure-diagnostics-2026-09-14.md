# KV16 结果核验与补充诊断

主实验启动后、终点评测前写入。主计划及通过门槛不变；以下均不做优化更新，不据此改训练预算或选最终权重。

1. 对本批每个最终checkpoint重算全部16384测试答案及1024交换答案，与保存的GPU逐项预测比较；校验数据、源码、初始化、每步计数、优化器和调度状态。
   另在最终权重上以eval模式测完整训练集准确率，用来区分训练拟合不足和训练/开发差距；这是事后描述，不用来改权重或门槛。
2. 在测试答案位置记录两层的选择集合，统计问题所对应的源值位置是否在集合中。标签仅用于事后描述，绝不进入选择器。覆盖率不等于注意力权重或因果贡献，学习索引器打分仍读取全部位置。
   同时统计预测值是否属于前文16个候选值，以及各源记录的正确数和被预测次数，用于描述错误类型，不用于改门槛。
3. 对固定掩码计算两层含残差的布尔可达图。利用已有交换题，找出两个被交换的位置均不可达的样本，检查这些样本的原题/交换题logits及预测是否相同。当前模型的其余操作都是逐token操作，静态掩码含自身，因而该图足以覆盖两层注意力和残差的输入依赖。此检查只适用于固定选择控制，不推广到内容依赖的学习路由。

第3项是新增的结构性正确性诊断，而非预注册论文假设或原创定理。不使用其结果修改主实验的成功标准。所有诊断保存分组计数及代码，0优化更新。
