# 32K续训结果：把省下的时间用于更多更新

完成UTC：2026-09-16T02:37:23.908930+00:00。四条已有轨迹各从64续至128步，新增256更新；完整参数、AdamW、调度器、随机状态和数据顺序连续，学习率沿用0.0001尾段。目标是较低成本与足够接近的质量，不要求稀疏质量超过密集。

## 当前能支持的直观结论

相同128步下，稀疏节省17.51%的训练循环时间，PPL代价6.84%；新64题短题下降0.78pp、无原文相同、32K下降7.03pp。这是一个实测成本与质量折中，适合按任务能接受的误差范围判断。

利用密集64步的训练时间，稀疏可完成77步：PPL代价7.57%，32K下降4.69pp，短题/无原文各增加0.78pp。该点只剩0.74%的时间余量，属于近似等时比较；不能同时把它说成节省17.5%并获得77步质量。

把稀疏从77继续到128步，语料PPL略有改善，但新题32K正确率没有随之上升。密集64和128的平均质量也几乎相同。因此不能只靠增加步数就保证任务质量恢复；保留密集64及零更新参照后，当前尚不构成达到某一质量的最低成本优势。零更新密集的32K成绩为50%，高于两种已适配模型，说明这套语料适配对该任务也有代价。

128→256步扩展已按事先固定的校准收益条件自动启动，继续观察低学习率尾段的收益边界；本报告不把未完成的256步结果混入。
