# QK恢复诊断的相关工作边界

2026-09-16：阅读原文 https://arxiv.org/html/2606.11052v1 ，Attention Amnesia in Hybrid LLMs (2026-06-09)，第5节提出恢复微调前Q/K并保留其他参数的QK-Restore；还提供Procrustes变体。其主要设定是混合线性注意力的CoT-SFT，附录L涉及纯softmax模型。恢复Q/K及以路由漂移解释长上下文退化均不能主张为本项目原创。

另核对LongLoRA摘要 https://arxiv.org/abs/2309.12307 ：稀疏注意力辅助高效长上下文微调的宽泛方向已存在，不能仅凭稀疏训练、密集评测构成新贡献。

本轮只采用已有QK-Restore作为低成本基线，评估密集与K32训练的同设置对照。我们使用Qwen2.5-0.5B LoRA继续语言建模，并非复现前作的模型/数据或证明前作结论。若同样解释两组退化，则不把一般微调遗忘说成稀疏特有机制。无新方法主张，不改变训练成本主目标，不新增训练。旧32背景开发任务和9个已暴露WikiText窗口只用于诊断；新背景结果不用于该基线的选择或独立确认。
