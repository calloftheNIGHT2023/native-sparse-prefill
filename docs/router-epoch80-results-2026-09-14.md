# 新卡迁移及40至80轮续训结果

两种学习索引器在80轮均过门槛；此前40轮的差距在本配置中主要表现为学习延迟，不能称为无法原生训练。

新卡A40已完成当前实验恢复，并完成三组续训。恢复时没有从零重新训练，也没有只给落后组增加轮数。原40轮结果、源checkpoint和计划均保留。

说人话：让一个小模型根据前文的“键—值”对应关系回答问题。精确选择对照直接用主注意力分数挑位置；另外两组让一个16维或64维的小索引器学习挑位置。之前在40轮时，两组索引器选路训练的模型答得很差；这次只增加训练时间，检查它们到底是学得慢，还是在这个设置下始终学不好。换掉前文的值后再问，是为了检查模型是否真的跟随输入作答。

## 证据范围

这是一组固定种子、长度64、437760主干参数的合成MQAR实验。完整因果主QK仍作为KL教师，所以既不是全程高效稀疏训练，也没有验证真实文本、长上下文或Qwen第四代架构。跨GPU的并行浮点结果不保证逐位重现，但迁移前后全部旧测试答案已核验一致。

前一批冻结主干时16维索引器可达到100%；40轮联合训练时，最终换回精确选择也不能恢复准确率。当前延长试验进一步辨认这是否仅是时间不足。这些都是诊断证据，不等于新的方法贡献；[MSA](https://arxiv.org/html/2606.13392v1)已有训练冷启动/预热，[RTPurbo](https://arxiv.org/html/2605.16928v1)已有低维索引器拟合，[KSA](https://github.com/awni/k_sparse_attention)已有直接取得主任务梯度的路线。

不要继续把已知“早期选择误差导致学得慢”换名申报。下一步只有在明确可证伪的新机制/实际训练成本收益并查清重合后才扩模型；新方法实验前还需要既有强配方与独立训练种子。当前没有确认论文级原创贡献。
