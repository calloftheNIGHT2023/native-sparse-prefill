# 更窄的候选：稀疏监督中的注意力头混合权重

本次不再把“看value”“输出对齐”或“因果证据训练路由”作为新贡献。Value-aware Approximate Attention（EMNLP2021）、Stem、SSA、Learning What Matters已有直接内容，见下列证据范围。均匀集合外抽查已暂停扩训。

## 待检验的机制

设某query的第h个注意力头在稠密状态下对token j的概率为p_hj，选中token集合S（含因果尾块），保留概率质量m_h=sum_{j in S}p_hj。稀疏前向中该头的概率变成p_hj/m_h。

若先在每个头上做稀疏归一化再平均，各头的混合权重仍是1/H。若先平均稠密头再限制到S，正确的条件混合权重应是m_h/sum_h m_h。这两个目标一般不同；例如几乎没选到重要内容的头，会在稀疏平均中被相对放大。这里“正确”只相对于复原稠密教师条件分布，不意味着这种教师必然有更好的语言模型效果。

精确恒等式：`mean_h[m_h * softmax(logits_h restricted to S)] = mean_h[p_h restricted to S]`。先按该式校正每头，再做块max pooling和归一化，即可复原限制在所选块上的稠密教师。这是条件概率代数，不是新的定理。

关键证据边界：QSA式20写的是教师在选中块上的重归一化，公开文字不足以确定其实现是否先计算完整稠密教师。若官方本就采用稠密教师限制到S，本候选的精确对照只是在还原该语义；不能把我们先前的逐头稀疏归一化代理当成官方训练缺陷。可能值得研究的仅是“用少量额外QK采样近似保留稠密教师语义”，其有效性、成本和新颖性均仍待验证。

简单反例：两个头的三token概率分别为[.80,.19,.01]和[.001,.009,.99]，只选前两项。稀疏平均认为第二项更重要，稠密教师限制后认为第一项更重要。实现检查覆盖该反转及精确校正、全量抽样还原、文档边界和因果尾块。

## 可实现近似及其限制

主前向仍只用S。训练时额外均匀抽查两个未选完整块，以“未选块数/抽样块数”加权估计每头未选区域的exp-logit和，再估计m_h。与旧抽查方案的区别是：抽样只帮助校准头混合权重，不把抽到的块加入KL比较支持集合或主前向。推理移除该估计分支。

这利用常规有限总体抽样。被估计的分母和可以无偏，但取倒数/比值及随后归一化并不无偏，不能称为无偏KL。当前CPU实现仍缓存完整QK；实际GPU成本尚未实现。精确校正对照需要稠密教师，只用于判断该机制是否有价值，不能宣称其免费或一定构成性能上界。

## 定向排重结果与来源

| 原作及核对范围 | 对当前候选的约束 |
|---|---|
| [Value-aware Approximate Attention](https://aclanthology.org/2021.emnlp-main.753/)，官方摘要 | 关注注意力输出而不只概率已是既有问题；不能以此立新题 |
| [SSA](https://arxiv.org/html/2511.20102v1)，§3式7–10与alignment描述 | 已有稠密/稀疏输出双向对齐及未选KV梯度不足讨论；比旧定向筛查更直接，应补入 |
| [Stem](https://arxiv.org/html/2603.06274v1)，§2.2式7及§2.3 | value幅度影响选择及prefill预算分配已有方法 |
| [COBS](https://arxiv.org/abs/2607.09052)，官方摘要 | 以块注意力质量、统计矩与输出近似解释选块已有工作；此轮不声称全文精读 |
| [Learning What Matters](https://arxiv.org/html/2607.21692v1)，摘要、实验及结论 | 因果证据监督路由已有直接研究，不能只把attention imitation换成因果标签 |
| [KVpop](https://arxiv.org/html/2607.05061v2)，附录D.3 | 已明确用稀疏LSE近似稠密normalizer来构建未来注意力标签；归一化近似本身并非空白。本候选限定为同query多头聚合的失配与校正，未确认已被该节直接实现，但不宣称排除了全部重复 |

原始网页及抓取清单在 `literature/objective-screen-2026-09-14/`。关键词包含value-aware/output reconstruction/sparse indexer normalization bias/head-wise renormalization/teacher normalizer。decode文献只用来查相近机制，研究任务仍是训练与prefill。

## 已固定的验证顺序

1. 已做只读开发集诊断：三个检查点、两层、三个索引器种子。在第5层，稀疏和稠密条件教师的首选块有约14%–25%的query不一致；两个抽样块在六个检查点/层均降低目标分布TV差，但不能据此推断模型效果。
2. 在最终公开权重与step1000两个已有数据集上，固定同一校准索引器、1200步、三个种子及第2/5层。比较原监督、精确normalizer校正、两块采样校正、旧扩大KL支持的抽查、评分预算匹配原监督。该轮复用历史数据，是探索性机制验证。
3. 只有低成本校正稳定胜过普通原监督和评分预算匹配对照，才再做新数据/更长上下文。需要扩大的证据必须同时含实际NLL、稳定种子、相关工作边界和成本记录；不以目标TV下降替代最终效果。
