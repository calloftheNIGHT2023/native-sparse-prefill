# 求和配置改变稀疏路由：真实模型受控结果

本轮确认：固定权重、固定文本、固定稀疏预算时，低精度块均值的求和配置可以改变路由及下一词预测。当前结果是工程稳定性机制，不是新的平均质量提升，也没有完成论文原创性证明。

## 最终受控实验

Qwen2.5-0.5B base，revision060db6499f32faf8b98477b0a26969ef7d8b9987；24层全部替换块注意力。主干/权重FP32，注意力QKV为BF16。16段固定8K输入，batch1，B128，K2或K4（含当前块）。K、块大小与模型完全不变；只改变内部求和分组kBlockN=32/64/128，warps固定4、stages固定3。内核仍是固定版本官方代码，通过显式配置绕过自动选择。

预测指给定真实前缀时每个位置的下一词argmax，**不是自由生成整篇回答的变化率，也不是错误率**。三个配置的材料全部相同，不算独立训练或新增48段测试文本。

| 求和分组变化 | K | 原版改变的预测位置 | 原版变化比例 | FP32池化改变位置 |
|---|---:|---:|---:|---:|
| 32 → 64 | 2 | 33,014 / 131,072 | 25.19% | 0 |
| 32 → 64 | 4 | 21,416 / 131,072 | 16.34% | 0 |
| 32 → 128 | 2 | 33,333 / 131,072 | 25.43% | 0 |
| 32 → 128 | 4 | 20,972 / 131,072 | 16.00% | 0 |
| 64 → 128 | 2 | 33,340 / 131,072 | 25.44% | 0 |
| 64 → 128 | 4 | 21,240 / 131,072 | 16.20% | 0 |

FP32池化在这些对照中的逐词NLL也逐位相同；稠密控制的预测及NLL同样一致。这里只保证测试过的模型/输入/配置，不声称任意硬件或输入下FP32均可保证位级一致。

## 单层机制证据

同一份保存的真实QKV（8192×14×64，KV头数2）上，12种官方候选求和配置、两种累加精度、K2/K4，共48个条件。BF16累加最多改变26912/114688个query-head行的选块，即约23.47%；输出相对Frobenius差最多0.1160。FP32池化再转回BF16，在这12种配置间池化结果、路由和输出均相同。每个固定配置自身重复两次均一致。

证据支持“改变求和配置足以改变稀疏路由”的因果路径。早期两个进程未记录autotuner实际选择，不能把那次重跑的每一个差异全部归因于某一已知配置。最终受控批次已记录显式配置及门槛阶段的autotune cache。

## 平均损失与稳定性分开判断

NLL越低越好；差值为FP32池化减原版。同一段文本做配对，按16个文本窗口bootstrap，95%区间不是逐token独立样本的区间。全体稠密平均NLL约2.359153。

平均NLL接近，并不意味着逐位置预测一致。当前结果没有显示足以开长训的稳定平均质量收益；更明确的变化是对求和配置的稳定性。FP32池化不是本项目提出的新机制，且当前实现临时复制FP32 K，尚未做性能优化或端到端速度测量。

## 从初测到最终结论的修正

1. 首个Pythia批次因日志字段seconds重名退出；已修复并保留原始失败。
2. Pythia第二批虽完成160个条件，但逐段插入的EOS主导了损失。抽查2048位置中16个EOS占总损失68.8%，这些人工EOS平均NLL约1202.75。该批次不用于质量结论。修正后按自然换行拼接语料，不选择性删除难预测token。
3. Pythia后两种数值协议未通过原生eager与Flash适配器的既定一致性门槛，保留失败，未放宽阈值。Qwen全BF16试跑也未过logit门槛；改为FP32主干/BF16注意力后通过。没有据此声称Pythia或Qwen架构自身损坏。
4. Qwen初测在1K/2K完成160个条件，8K完成80个；最初观察到平均质量差小。随后反序重跑前2段8K文本，稠密与FP32池化逐位复现，原版不一致。原先简单的“精度没有影响”解释因此被撤回，初测转为探索记录。
5. 显式固定32/64/128求和分组，追加240个完整模型条件，得到上面的受控结果。没有优化器更新。

## 与前人工作的关系

[Switch Transformer §2.4](https://arxiv.org/html/2101.03961v3)已有局部高精度路由；[Thinking Machines](https://thinkingmachines.ai/blog/defeating-nondeterminism-in-llm-inference/)已有不同执行形状/归约方式导致推理不一致及batch-invariance方法。不能把浮点加法不结合、提高路由精度或一般可复现性问题当新发现。[Triton文档](https://triton-lang.org/main/python-api/generated/triton.autotune.html)说明了配置自动选择机制。

本项目新增的是该固定FlashMoBA实现、真实Qwen QKV和受控完整模型上的证据：平均损失相近时，内核配置仍可能改变很多预测。它是否能支撑论文，需要进一步证明与上述工作的区别、跨模型范围、训练影响和修复成本；目前原创贡献未确认。Thinking Machines页面已通过网页工具核查，本地HTML下载403，sources.json明确保留此限制。
