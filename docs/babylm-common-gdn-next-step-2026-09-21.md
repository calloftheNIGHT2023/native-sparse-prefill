2026-09-21 的固定8窗诊断完成36次前向、32次反向、0次更新。GDN 占 D/W **带计时钩子的前向**约82.48%/80.12%；这不是完整训练耗时占比。共享 GPU 当时繁忙，结果只用于定位当前实现，不证明架构本质或稀疏加速。

## 唯一首选改动

新增独立适配器，D 与 W 使用完全相同的优化，不修改既有冻结科学源码。当前 `src/babylm_hybrid/model.py` 的 `SegmentedGDN.forward` 每层把 GPU 上的 `segment_ids` 转成 Python 列表，再做 `zeros_like → index_copy → stack`。对于**已验证的 batch=1、单个连续有效文档、无填充、每窗重置状态**的输入，适配器可直接调用原 `self.core(x, cache_params=None)`，消除重复分段和重排。

快速路径只能由固定窗口读取器提供的**可信 CPU 元数据**授权：核验窗口清单及 token 文件 SHA、输入长度、`single_segment` 与 `reset_model_state_before`，并确保元数据对应本次实际输入。不能仅凭形状、默认值或未经核验的布尔标记判定；不能忽略调用者传入的任意 `segment_ids`。多文档、填充、其他 batch 或缺少可信信息时保留原始通用路径。不要以 GPU `all().item()` 重新判断单段而引入同类同步。

## 不变项与验证门槛

- 固定现有最终 D/W 检查点和 SHA、模型配置及全部参数。保持 GDN 递推、因果卷积、每窗状态重置、Q/K 归一化、`SigmoidGatedNorm`、全局注意力和损失定义不变；不调整学习率、精度或优化器。
- 新适配器、执行协议和依赖均单独冻结源码 SHA；原实现保持可调用。原版与适配器使用相同检查点和输入，验证 logits、LM loss、每个具名参数梯度，沿用 FP32 **`atol=1e-6, rtol=1e-5`**。这是张量/梯度等价阈值，不与迁移时的逐窗/总体 NLL 绝对阈值混用。
- 先用 tiny 输入覆盖63/64/65-token边界、单段、填充和多文档，验证通用回退及跨文档隔离；再冻结有界真实窗口验证。权重及持久状态前后逐张量 SHA 必须一致，0次优化器更新。失败原样保留，不放宽阈值。
