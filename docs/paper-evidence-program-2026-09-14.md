# 原生稀疏训练：形成论文证据的工作计划

用户要求持续实验，直到具备论文支撑。这个目标不保证结果为正或必然录用；不通过改变门槛、删掉负结果或遗漏成本来宣称贡献。总预算500美元，现有首阶段30美元约束不变。

## 尚未解决的核心主张

研究训练期间稀疏计算的分配：是否有少数层在能力形成阶段对全局信息覆盖特别敏感，把有限的额外覆盖预算集中到这些层，能否减少原生稀疏训练的学习延迟？此为待验证假设，尚未声明新算法。

目前已有64、128长度Zoology稠密基线通过；这不是论文贡献。旧均匀集合外抽查、头间归一化候选已经关闭，不重启换名。与Qwen相同的架构标签也不构成贡献。

## 需要形成的证据

1. 对现有方法明确可重复的缺口：至少三个训练种子、两个任务条件；与原生稀疏及合理预热同时比较。
2. 新的解释或机制：提出可证伪预测，必要时在受限模型/假设下证明，不能用简单图连通事实替代学习定理。
3. 有用性：真实文本任务、较长上下文、主干确实更新；单个玩具查找任务不够。
4. 全成本核算：索引、分数生成、辅助监督、前后向、额外训练步、prefill时间和显存全部计入；不能将掩码零值当作已经节省FLOPs。
5. 稳健性与前作区别：对照当前强方法，保存原文定位和否定结果。不承诺穷尽检索或证明绝对无重复。

## 首轮固定机制筛查

复用作者64长度/4键值、10000训练/1000验证、batch32、128宽/2层/1头、seed123。全条件从完全相同CPU初始化和训练数据开始，统一转到同一A40 FP32。固定40轮，不以验证提前停止；CosineAnnealingLR的T_max仍100。独立新题1000条，种子2026091440，在全部40轮之后评估，不用于挑选停止轮数。

五条件：全稠密；第一步top-k；两层前4轮稠密；仅第一层前8轮稠密；仅第二层前8轮稠密。稀疏状态每个查询最多保留8个因果token，其中自己和前一token强制保留，另外6个由同层精确QK分数选择；无外部标签、无前缀答案特殊处理。三种预热条件在第9轮起完全相同。

两层×4轮与一层×8轮的额外保留连接数相同：每序列单层稠密2080个因果连接，k=8稀疏484个，差1596；额外8层轮、每轮10000序列，即127680000条连接。这是结构预算，不是实测省下的计算。当前参考实现仍计算完整QK和稠密AV掩码张量，绝不据此报告真实稀疏速度提升。

记录全部每轮准确率、损失、逐步梯度/学习率、到达90%/99%的步数、独立新题、查询/源值干预、实际GPU时间和峰值显存。新题只用于最终报告；首轮可作探索性筛查，不据同一套测试反复调参。

筛查决策：若原生top-k已与稠密及预热相当，则不制造预热需求；若所有稀疏都失败，先定位学习信号，不能称层级方法有用。只有单层预热在独立新题上明显优于原生与预算配对预热（初筛至少5个百分点），或达到99%的逻辑注意力累计连接数至少降低20%且终点不劣超过1个百分点，才进入独立种子/任务确认。即使通过，这一精确分数参照也不能证明便宜索引器或真实训练成本优势。

## 最近工作与重叠边界（定向阅读）

- [MSA](https://arxiv.org/html/2606.13392v1)：§3.2与附录B.2—B.4已有预热、梯度来源和局部路径研究；不能将早期不稳定作为新发现。
- [Cerebras](https://www.cerebras.ai/blog/compressing-kv-cache-memory-by-half-with-sparse-attention)：One-shot sparse layer selection heuristic，已按预训练模型的层敏感性选择永久保留的稠密层。我们只能继续检验训练早期、最终全稀疏、时段预算配对这一差别；单纯选敏感层明显重叠。
- [LongLoRA](https://proceedings.iclr.cc/paper_files/paper/2024/file/211ab571cc9f3802afa6ffff52ae3e5b-Paper-Conference.pdf)：已有移位局部块及跨头/层安排，不能将窗口位移当作新机制。
- [RRAttention](https://aclanthology.org/2026.acl-long.1199.pdf)：标题/摘要定位为长上下文推理的逐头轮转块位移，尚未全文核对，不能声称排除所有相近机制。
- [Liu的关联回忆实验](https://kindxiaoming.github.io/blog/2026/sparse-attention-6/)及[随机嵌入实验](https://kindxiaoming.github.io/blog/2026/sparse-attention-8/)：学习延迟、嵌入维度、数据量、学习率及噪声已有直接探索；观察到晚期准确率跳变不构成新发现。

检索覆盖训练期稀疏、layer-wise/layerwise warmup、跨层采样、路径、curriculum、hysteresis等组合；不是穷尽查重。OpenReview两个PDF入口被网站验证页阻挡，未将其当作已读全文。当前仅允许低成本机制筛查，不声称原生训练领域存在已确认空白。
