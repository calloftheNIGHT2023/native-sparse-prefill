# 完整一轮尺度试验之后：先排除简单局部注意力已经足够的解释

这是本机后续方案，未派发新训练。当前 C2 有限队列已经结束，自动监控仍暂停。本方案不改变已完成 D/E/F 的结果、阈值或任何冻结文件；F 指仅将索引器分数尺度改为 1/√128 的候选。

目前 F 的完整开发集点估计接近 D，优于原 E。即便这次差距在更多种子上成立，也尚未回答“是否真的需要学会选块”。先做原计划的固定局部窗口 W，比立即扩大 D/E/F 种子更能排除核心替代解释。W 不是临时把训练好的 F 改成局部 mask，而是从共同随机主干初始化、全参数、第一步起固定局部连接，完成同样的一轮。

**唯一下一候选：原定义的纯局部 W。** 三个 global 层每个 query 选择最近的至多 64 个完整块，再保留与 F 相同的当前不完整因果尾块。其他九层 GDN、共同主干参数初始化、训练窗口与顺序、16窗更新累积、1413 更新、10,001,709 真实训练词暴露、tokenizer、主干学习率与裁剪、词数退火调度均保持一致。短于预算的历史使用所有可见完整块。每 query 的连接预算必须通过逐项计数与 F 一致；不能仅使用全局平均保留率。

W 无需索引器和其辅助目标。模型共享主干的初始化必须精确匹配；索引器额外参数、router 更新和计算成本的差别分别记录。这是“学习式选块配方”对“固定局部配方”的比较，不能把所有质量差异只归因于内容路由。现有 reference 的完整 QK 分配仍使其不构成稀疏加速实验。

最终只评预定的第1413步模型，完整18792窗dev，按目标token加权LM NLL；训练末100步固定1314–1413，并分别报 exp(加权NLL) 与逐step PPL算术均值。过程面板仅诊断，不选择checkpoint。数据、评分、窗口顺序与 D/E/F 保持一致。未见任务和独立种子仍是后续确认集，不能把当前探索dev包装为盲测。

**运行前应完成的工程门槛。** 新增 W 支持不得改写原冻结模型源码；用新版本/薄封装实现可训练的确定性局部策略，验证前向、反向、因果、文档边界、相同连接预算和可重复初始化。已有 RoutingDiagnostics 用于临时评估，不应未经训练梯度验证直接当训练入口。先做有限数值小检查，按当前真实硬件短测冻结运行时长和整批费用上限，禁止未知余额下无界扩队列。新工程门槛未通过前不运行整轮。

**预期判定，须在看到 W 结果前冻结。** W 与 F 一样好、更好，或者 F 对 W 的差距小到不足以支持实用价值时，不再扩大本设置的“学习路由必要”主张；这不是统计等价声明。可将 NLL_W − NLL_F 至少达到 log(1.01) 作为建议的工程筛查门槛，即 W 的 PPL 至少高1%，但此数值当前仅是待运行协议明确采纳的候选，不是已经通过的论文非劣界限。若 F 对纯local W 有实用优势，仍需更强简单位置规则及独立种子确认，而不是直接宣称方法成立。

纯local W 不含 sink。若它被 F 击败且继续主张学习选块有价值，另行冻结“第一个块＋最近63个完整块＋原尾块”的 sink+local 对照；它是另一配置，不能改名冒充原 W，不能看分后替换原结果。当前不同时扩两个 W 或追加种子。已存在的密集预热/稀疏切换文献与后续 L 对照只在具体主张需要时继续补齐。

当前可支持的表述是“这一次小型混合模型从随机初始化进行全参数稀疏预训练时，单因素分数尺度配方改善了训练和开发集质量”。1/√128 不是已经证实的 QSA 公式漏项，现有证据也没有隔离 softmax 温度、梯度幅度、Adam/裁剪和移动主干特征的各自作用。全零 logits 的 softmax 是均匀分布；不能把全零比例直接叫做当前softmax饱和。完整Qwen、普遍的冷启动机制、新方法贡献与实际节约成本都需独立证据。
