# 固定六层组恢复密集注意力：事后层级诊断

动机：此前96题上K16训练/K16使用的16K正确率34.90%，dense训练/dense使用45.83%；直接把K16训练权重全改为dense使用反而29.69%。本轮检验部分层切换能否恢复。不是新的独立测试，也不是新的训练方案。

固定两个已有K16 LR1e-3、256步LoRA断点；24层按0-based分为0–5、6–11、12–17、18–23。每次仅一组6层用dense，其余18层继续K16。另跑全K16和全dense端点，均在同一权重上完成。每个端点96题预测需与已归档端点一致，四选项logit最大绝对误差≤1e-6；先在原模式通过四校准窗口NLL误差≤1e-6。任一不一致停止，不能放宽阈值掩盖实现错误。

只评此前96道RACE-M扩充16K题，完全相同token和答案，不重新选题。所有六种条件、两个种子均报告；不只汇报最佳组。种子0和1的四个组运行次序相反。报告配对正确率差、错误改正/新增错误、描述性区间及逐题prefill时间；多组比较和已观察数据的选择偏差明确标注，不以最佳值证明泛化。若出现有希望的组，后续需冻结配置并使用新的题目确认。

原位置表10%/50%/90%使用不同题，位置与题目难度混杂，只能作分组描述，不能用来证明位置因果效应。真正移动同一段落的定位实验需另行安排。

控制器900秒、每种子420秒上限，无新训练更新，无自动重复失败作业。原全层稀疏训练的约9.2%节时不自动等于本轮混合推理的节时，更不等于混合训练成本。
