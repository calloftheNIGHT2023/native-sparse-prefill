# Stage B 机制审查与最小固定特征诊断

日期：2026-09-20。状态：本机只读源代码/阶段A证据审查；tiny CPU 梯度探针已完成。下面的 B1 是供执行控制器冻结的协议，不是已跑结果。本报告没有加载真实95M模型、连接云端或更改原训练源码。

## 结论先行

建议保留一个有界、至多30分钟的B1，然后最多推进一个500更新、只把索引器峰值LR从1e-3改为1e-4的完整模型试验。不要从已塌缩的索引器权重开始比较“低LR能否救活”：大量query的所有点积已经非正，此时降低LR或乘正常数都不会生成ReLU梯度，得到负结果几乎是问题设置使然。

B1使用已有第137步稀疏主干的固定特征，但索引器重新使用原初始化种子，四臂初始张量相同、优化器状态清零，固定支持和教师。它回答静态问题上的步长/尺度敏感性；不能复现移动主干、动态topK及完整训练优化轨迹。B1不出现塌缩，不能成为否定完整模型低LR试验的理由；也不应因此再扩大局部超参搜索。

## 2. 数学与代码核对

当前合同是

\[
z_{hb}=q_h^T k_b,\quad s_b=\alpha\sum_h\mathrm{ReLU}(z_{hb}),\quad
S=\operatorname{stopgrad}(\operatorname{TopK}(s)).
\]

主注意力只在S对应token和因果尾块上归一；其概率先跨head平均，再对每个完整块取max，在S内重新归一，得到停止梯度的教师T。学生为r=softmax_S(s)。设Z=sum(T)，那么固定支持上的实际目标满足

\[
L=\sum_{b\in S}T_b(\log T_b-\log r_b),\qquad
\frac{\partial L}{\partial z_{hb}}
=\alpha(Zr_b-T_b)\mathbf1[b\in S]\mathbf1[z_{hb}>0].
\]

教师正常归一时Z=1，才化简为常见的alpha(r−T)。代码对教师分母使用clamp_min(1e-30)；若选中完整块的教师质量极小或全零，Z不一定为1。所以B1必须显式检查教师质量，不能把另一种零梯度归为ReLU。当前没有证据说明真实运行发生过该数值边界。

源代码的梯度边界是明确的：

- indexer输入hidden被detach，KL教师也被detach，因此辅助KL不更新主干。
- topK由detach后的分数生成布尔掩码，主语言损失没有通向索引器的可微路径。
- 索引器主要依赖所选支持上的KL学习；未选块在该query上的直接分数梯度为零。
- 全部相关z<=0时，KL即使非零，该query的ReLU路径梯度仍为零。乘正尺度、降低LR或向分数统一加常数都无法直接恢复这条梯度。
- 这不是永久死亡证明：共享参数可由其他query改变，主干特征持续变化，优化器历史状态与权重衰减也可能改变参数。RMSNorm采用1+weight的零中心增益，衰减weight与简单缩小有效gain不同。
- 三个indexer一起构成独立AdamW参数组，并共同按norm1裁剪；主干另裁剪。betas=(0.9,0.95)、eps=1e-8、weight_decay=0.1、aux_weight=1。原索引器峰值LR1e-3，和主干共用真实词暴露warmup/cosine乘子。

现有实现与项目声明的“多头ReLU聚合、选中支持KL”合同一致。本轮未重新核验远端论文原文；已记录的QSA公式没有显式1/sqrt(d)，不能把scale=1直接命名为漏缩放bug。正尺度不会改变固定权重的topK顺序，但会改变学生概率和后续梯度；Adam的自适应归一、epsilon和裁剪使“缩小scale”“缩小KL权重”“降低LR”不等价。

## 3. 已完成的tiny CPU验证

结果收据：`logs/babylm-stage-b-mechanism-audit-20260920.json`。

1. 所选两块教师为[0.8,0.2]、所有点积为负时，原ReLU的KL=0.192744757、梯度范数严格为0；scale改为1/sqrt(128)后仍相同。
2. 同一标量例子使用LeakyReLU(0.01)，KL=0.190501788、梯度范数0.005962500，未选块梯度仍为0。这只验证非零负区导数，不证明该候选有效或新颖。
3. 正区原ReLU自动微分与解析式一致，未选块梯度为0。
4. 教师质量全零时，即便点积全正也得到零损失/梯度；因此教师质量需要单列检查。
5. 冻结源码的tiny GlobalAttention：主输出的梯度不能到达indexer；辅助KL的梯度不能到达输入hidden或主注意力参数，但能够到达indexer。

原探针有一次测试oracle的dtype问题：torch.where的标量分支生成float32，而被测目标为float64，导致Leaky导数比较误差6.66e-11超过原1e-14阈值。保留失败记录后，仅用显式float64修正测试oracle，误差降到4.34e-19，未放宽阈值、未改模型源码。

包含该失败和复核的实际账目：1次tiny注意力组件前向、6次标量路由目标前向、8次autograd反向调用；0完整LM前向、0优化器更新、0GPU调用。另有一次读取summary键名错误，随后按真实routing_summary字段修正；该错误没有模型调用。

## 4. B1最小可辨识协议

机器可读建议位于上述JSON的`proposed_b1_protocol`，执行控制器还须冻结新硬件、入口源码、时间/费用上限与缓存SHA。

### 样本与缓存

- 使用训练manifest `data/babylm-2026-windows-v0/manifest.json`，SHA `08e19b2fe6d1dc5b957c28e2d0503d9da3fdd04e481900da947f4fc281f1a218`。
- 每个来源只在L>=1024的窗口中按固定SHA排序，前2个fit、再2个holdout；共24窗，fit12/holdout12。六源符合长度条件的窗口数分别507/2747/1701/1800/177/20，均足够，不需要自适应换数据。
- 各窗只取有LM监督且完整可见块>64的query。在一基位置260–512、513–1024、1025–1536、1537–2047分别按固定SHA最多取8个；不足不从别桶补。JSON保存零基query_indices。共744个query位置/层，三个层相同位置；抽样分母逐层、逐来源、fit/holdout分别报告。
- 总输入46,440token，三层float32原hidden约427,991,040B。只在旧E的第137更新主干上前向一次每窗，原路径保持不变，缓存三个global输入、固定S/T、完整因果概率参考与ID/SHA；整个缓存上限1GiB。
- holdout只表示没有参与B1索引器拟合。这些窗口来自主干见过的训练语料，不是独立语言质量确认集；来源边界不应被夸大为完全独立文档。

### 初始化、教师与四臂

四臂都使用原indexer_seed=20260918的fresh初始化及全零Adam状态，不从已塌缩的索引器恢复。必须沿用原顺序：逐global层构造indexer（默认Linear构造消耗RNG），随后对该层Linear做std0.02的原初始化，再进入下一层；不能先构造全部层再统一初始化。记录并核验共同初始参数SHA。

| 臂 | 恒定LR | alpha |
|---|---:|---:|
| 原峰值配方 | 1e-3 | 1 |
| 只降LR | 1e-4 | 1 |
| 只缩尺度 | 1e-3 | 1/sqrt(128) |
| 交互诊断 | 1e-4 | 1/sqrt(128) |

共同支持S由同一fresh索引器在alpha=1时一次选出。教师必须按原合同，在S+尾块上逐head softmax，再跨head平均、block-max、S内归一；固定后不再更新。不能换成完整dense教师来训练四臂，否则同时改变了监督目标。完整因果概率质量仅用于评价动态topK覆盖率。

每臂200次router-only optimizer更新，循环相同12窗顺序；每次一个窗，同时训练三个indexer。每层对抽样query的KL取均值，再取三层均值，aux_weight=1，三个indexer共同clip1。其余AdamW设置不变。恒定LR明确是静态峰值步长压力诊断，不冒称原warmup重放；抽样query目标也不等同原全token归一梯度。

### 观测及预先规则

在0、25、50、75、100、125、150、175、200更新记录fit/holdout。最终比较固定200更新，不选择最优中间点。逐层记录：全部可见点积非正query率、可见及选中logit跨度、学生和教师熵、固定支持KL、梯度范数、裁剪系数、每参数及有效RMS增益的更新比、动态选块变化率，以及重新选出的动态topK在固定完整因果概率上的coverage。固定S自身的coverage不会变，不能把它作为优化进步指标。

所有臂使用相同固定教师，报告KL绝对值与相对各自初始化的变化；另报告统一alpha=1评价，区分单纯温度效应和学到的参数/排序变化。alpha变化造成的零分消失或KL下降，不能单独触发成功判定。

代码门槛：因果及块预算精确满足；全部值有限；教师质量误差<=1e-6且没有零质量行。违反时停止并审计，不静默删query。其余预定阈值只是有意义的小样本工程筛选：

- 路由退化标签：某层holdout非正率相对共同初始化增加至少10个百分点，或终点达到90%以上且比初始化更高。
- 候选筛查：在发生退化的层，较原配方降低非正率至少10个百分点；三层平均动态coverage至少提高0.01，任何一层不下降超过0.01；holdout固定支持KL不高于原配方+0.01nat。
- 指标矛盾时全部报告，不因某一层/某个时间点好看而挑选方案；这些条件不构成显著性、语言能力或论文证据。
- 总墙钟上限30分钟、800次router-only更新，不加候选或额外随机种子。特征提取LM前向与router前向/反向/更新单独记账，原科学训练计数保持不变。

## 5. B1之后是否直接500步

不建议完全跳过梯度与固定目标的检查，但也不应让B1成为漫长的新研究项目。上述tiny检查已说明代码的梯度行为与声明目标一致；有界B1只用于辨别静态优化敏感性。

- 若低LR在B1减少退化且改善动态coverage，优先只做低LR1e-4的500更新全模型验证。
- 若B1没有复现退化，记录“静态设置没有复现”，仍可做这一个低LR试验，因为移动主干/动态支持被B1主动去掉了。
- 若只有尺度臂有效，先报告交互与目标熵证据；不要同时更改LR、尺度与激活后声称找到原因。
- 若固定目标/梯度数值错误，先修工程问题；不能用训练覆盖错误。若四臂都没有进展，也不应在B1中继续调几十个超参。

全模型500更新必须fresh随机初始化、第一步稀疏，保留原1413步一轮调度前缀、同数据顺序、主干LR/批量/裁剪与token账目。只改索引器峰值LR，不能把500更新重新定义为快速退火终点。看固定500终点与既定过程面板，保留原137/693/1413证据；与旧500更新只作同条件探索比较，迁移GPU不混计速度。零分减少但coverage/LM NLL不改善，不能声称修复冷启动。

从头固定局部W仍是必要后续对照，但不由B1自动展开。原reference没有真实稀疏加速；任何配方改善仍须完整一轮、独立确认及实际成本证据，不能把本轮机制诊断包装成新方法。
