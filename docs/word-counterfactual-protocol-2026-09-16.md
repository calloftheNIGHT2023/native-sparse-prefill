# 直接词值反事实：先检查密集底座能否利用上下文

选项轮换完整核验后，短题K32减密集为+0.39pp，但32K均衡后仍为-14.84pp，文章配对95%区间[-21.09,-8.59]。字母顺序不足以解释旧长题差距；同时等长原文替换没有测出稳定原文作用。因此暂不重复旧配置训练，先建立具有明确事实依赖的能力诊断。

采用32组背景，每组两份事实：只把“秘密词是apple”中的一个token改成另一个词，其余输入完全不变。四个候选是apple/copper/marble/velvet，都是带前导空格的单token；目标在各输入条件全局均衡。题目直接问秘密词，评分直接比较四个词的logit，避免A/B/C/D符号绑定。仍是强制候选评分，不是自由生成。

背景沿用旧任务的无关训练集文章token；事实是新构造的随机赋值结构，不从原RACE问题推断。4个事实位置10/35/65/90%，每位置8组；每组短原文、无原文和32768-token输入。逐例验证两个事实版本只相差一个token，无原文配对输入完全相同。示例用不同的四个词，不包含任何待答实例。

仅运行原密集底座（零LoRA），先完成64个短题和64个无原文题。预先冻结短题能力门槛：至少56/64正确、至少24/32配对两版都正确、比无原文多至少24题正确。未通过则停止，不做长题或稀疏比较。

短题通过才做64个长题。长题门槛：至少48/64正确、至少20/32配对两版都正确、比无原文多至少24题正确。这些是排除无效测量的操作门槛，不是统计非劣界限。失败同样保存，不在本批调提示模板，不用双方接近随机猜测作为稀疏质量好证据。

最多192次任务前向，0训练。4段旧校准NLL仍必须在1e-6内重放；上限600秒，约0.1233美元实验GPU费（不含设置、空闲与存储）。成功通过后才考虑固定模板的新样本与已有稀疏检查点比较。

这是常规受控检索能力检查，不是新算法、官方RULER或论文级任务验证。此前四条相近catalog记录的检索短题失败4/32，本次换成单一事实直接词完成，用来分开基础读取能力与多记录键匹配/字母选项绑定；不覆盖或抹去先前失败。
