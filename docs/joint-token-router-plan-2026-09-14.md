# 在线索引器与主干一起从头训练：开跑前固定

静态冻结容量检查四组均过门槛，因此进入原计划的联合训练定位。仍用已有A40，不增加GPU；总预算500美元、原首阶段30美元不变。此次用户同意略增开销没有被解释为无限预算。实际Pod费率及累计账单未核实。

三组：exact_r16_shadow（精确主QK选路，同时训练不参与选路的16维索引器）、learned_r16、learned_r64。主干复用上一轮保存的随机初始权重，而非学成后的权重，2层/1头/437760参数、长度64、top8含最近2token。四十轮、每轮原训练集10000序列、batch32、无额外打乱。主干AdamW及100轮cosine调度参数沿用Zoology基线；索引器AdamW lr0.001/weight_decay0，无调度。两层KL求和，索引器输入与教师均stop-gradient；CE仅更新主干，KL仅更新索引器。每组12520主干更新及12520索引器更新；不能把两个优化器当成两倍数据。

所有组均使用gather主注意力、相同所选槽位dropout实现。精确组也进行索引器拟合，因此监测/代码路径接近。16/64维组参数量不同，是容量对比，并非等参数比较。主干初始张量hash一致，索引器固定seed2026091470，训练dropout seed123。已有训练/验证数据不变，新独立评测1024序列seed2026091471，运行前生成并检查不与旧数据整行重复，三组结束才评测。源值交换干预也提前固定。

真实gather主注意力不代表全程训练稀疏：完整因果主QK作为在线KL教师仍有二次开销。这是常见KL索引器训练基线，不是新算法、QSA/MSA复现或端到端加速证据。训练目标还包含本合成任务的4个答案/序列，不是自然文本预训练。

主要读数：新题、源值交换准确率，首次开发准确率>=99%的轮数，主干/索引器训练曲线与KL。精确组须新题和交换均>=99%才视为有效可学对照。某学习索引器若两项均>=99%且距精确组各不超过1个百分点，可称此配置从头学会；若所有组通过，则不能宣称这个任务已暴露联合训练障碍。若差距存在，仅定位现象，先独立seed复核及读取checkpoint做干预，不能直接声称新理论/新方法。不得根据这批fresh调整超参再作为同一确认测试。

每组最多12分钟，整批45分钟内部墙钟上限。每步JSONL、每轮曲线、每5轮含优化器/RNG的checkpoint、源码/数据/哈希保留；异常留failure checkpoint。开跑前检查完整模型前向/梯度对照、CE/KL梯度隔离与因果性。终止训练进程不等于停止Pod计费。
