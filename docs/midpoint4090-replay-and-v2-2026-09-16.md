# 迁移核验与同卡重评

新4090与旧6000Ada采用相同模型、检查点、torch2.8.0+cu128和原始扩展。三种路径各4段校准NLL误差为0。24条固定诊断中，12条32K长题选项分数完全一致；12条无原文题的最大logit差异0.125，其中dense有1条因原答案并列而改变argmax。原v1严格检查失败，保留归档，不改写为通过。硬件、短输入算子选择和执行历史尚未做因果隔离。

因此v2在同一4090重新评测全部固定0/64/128步：3个零LoRA基线+6个64步模型+6个128步模型，每个128条，共1920条；不新增训练，不混用旧卡短题分数。每个模型仍须通过原4段校准1e-6阈值。总上限3600秒（仅此评测GPU租金约0.74美元上限，不含此前迁移与存储），每模型上限360秒。模型和题目在运行前按SHA256冻结。

这轮回答训练中期到后期是否持续恢复、差距缩小来自何处；不能把开发集最高点视为独立验证，也不推翻此前256篇独立评测中的长题落后。
