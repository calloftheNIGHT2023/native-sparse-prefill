# A6000 首次 GPU 试跑与正式 D/E 开工依据

时间：2026-09-18 UTC。用户提供新卡并明确开始，随后要求继续，不以历史预算核对阻塞；这取代之前的停止指令。旧 LoRA 结果仍不用于本题。

## 已完成的实测

GPU为RTX A6000 48GB。代码与训练/开发文件146项原字节校验通过，运行环境torch2.10.0+cu128、transformers4.57.6、numpy2.4.2、tokenizers0.22.2，FP32、关闭TF32，未引入FLA/causal-conv新路径。

数值检查7/7通过，380项数值比较沿用原阈值；全支持密集/稀疏输出与主干梯度差0，优化器/参数/RNG重放差0。2次CPU与7次CUDA前后向、3次工程更新，均为tiny合成检查。

两组各12次工程更新、192个相同窗口、135,583输入token、80,982词暴露。共同主干初始哈希、顺序、LR、损失位置和数据指纹一致；主干与索引器按对应配方更新，检查点SHA另行核验。正式科学训练尚未因此完成任何更新。

## 费用和下一批边界

API核实GPU为0.53美元/小时；Pod报告1000GB容器盘和1000GB卷。因确切存储账单尚不可读，本批按0.81美元/小时作保守资源计费额度（非发票）。从Pod创建到预飞结束约14分钟，GPU估算0.124美元，含存储额度0.189美元。

完整D/E两组线性估算81小时，GPU约43美元，含存储额度约66美元；另留30%时间余量约105小时/85美元。这不是论文全部实验费用，也不保证余量足够。正式首对设置150美元整批上限、每组72小时硬上限，并记录准备/空闲；硬上限不是预计要花的费用。完整dev及后续真实任务费用另外纳入项目总账，真实任务版本和协议需看分前冻结。

## 正式科学比较

原科学draft的模型、train-only tokenizer、数据顺序、优化器、学习率、100M词上限均不改。D/E都重新从共享随机主干初始化，不续训预飞权重；每组预计99,998,882词暴露、163,224,857输入token、14,122更新。先D后E，同卡同环境；只运行这一对单种子先导，不自动扩到L/W/多种子/新方法。阶段快照/原始训练日志/快速dev面板沿既有协议，完整dev为后续主质量读数，过程面板不代替它。
