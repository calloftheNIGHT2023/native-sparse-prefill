# v1：参考算术对齐后的探索性成本协议

本协议在 v0 失败诊断完成后、AMP 计时开始前制定，是自适应后续实验，不冒充一开始就预先注册的方案。v0 的失败状态不更改，原先 dense-vs-sparse logits <0.01 的门槛也不宣称通过。

诊断依据：native eager 的复刻输出/梯度逐位相同；同一 BF16 Q/K/V 的 FP32 数学参考与 Flash 全模型梯度差约 6.24%，与 native eager 差约 25.73%。固定首层 Q/K/V 的 Flash 和全块稀疏前向/反向均通过既有 atol=rtol=0.03 的逐元素比较。因此仅将 native eager 当成唯一正确参考会混入中间结果的低精度舍入差异；这不意味着任何全模型差异都可以忽略。

新验证以相同 BF16 Q/K/V 量化和 BF16 输出、FP32 score/softmax/AV 算术为共同独立参考。稠密与全块稀疏分别满足 logits 相对 L2 <0.02、NLL 差 <0.05、LoRA 梯度相对 L2 <0.10，另需已有固定真实 Q/K/V 参考测试和当前长度因果检查。这里改变了参考与检验结构；它是新的验证标准，不能称为通过了原 v0 完整门槛。

只测 AMP BF16 的 8K/16K，各配置两个逆序轮次、稠密/K4/K16、prefill/前反向、3 次预热加 10 次计时。保留 FP32 主参数，全部 0 优化器更新。具体成本范围、输入选择、不用最终报告窗口、每进程 360 秒上限、遇失败停止等，沿用 v0。全模型 matched-reference 检查只有 256 token；真实长序列另做前缀因果与有限梯度检查，不能视为 16K 完整梯度参考验证。

本轮只决定算力成本是否有进一步研究空间，不决定数值差异对长期训练质量的影响。未来质量对照必须在同一数值后端内配对，并使用新冻结的数据划分。
