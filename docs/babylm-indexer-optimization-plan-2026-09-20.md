# 下一轮优化方案：先定位路由退化，再验证第一步稀疏的改进

状态：供审核的研究计划，未启动新实验，未修改已冻结训练实现。自动监控保持暂停。本文件不构成已完成的方法或新颖性证明。

## 1. 目标与已有证据

目标保持为：随机初始化、全参数、从第一个训练更新就使用稀疏注意力，以更低实际训练成本达到接近密集注意力的语言质量。BabyLM 小型混合模型用于检查假设；不能外推完整 Qwen，也不能用一轮小数据实验声称满足大模型计算最优 scaling law。

已完成的严格一轮 D/E 各 1413 更新、22,598 窗口、16,302,816 个监督 token，共同主干初始化、数据顺序和主干学习率一致。固定末 100 更新的 token 加权 LM NLL 为 D 3.654818、E 3.672284；PPL 为 38.660479、39.341657，E 高 1.762%。最终 48 窗面板 PPL 则高 3.553%。这两个口径分开报告，均不能代替完整开发集。

更值得查的是路由：已有面板日志中，所有可见完整块分数全零的查询比例从初始化 0.017%，变为第 250 步 97.028%、第 500 步 98.252%，终点回到 67.759%。全零且确实需要 top64 截断时，稳定排序选择最早 64 个完整块，另保留因果不完整尾块。终点有效截断查询零分率的已知下界是 62.600%，尚没有精确分层交集。

这表明当前实现存在训练后的路由退化，尚不证明它导致 NLL 差距，也不等于复现了原论文的冷启动机制。先诊断，再决定改什么。

已有证据：[一轮结果报告](babylm-one-epoch-results-2026-09-20.md)；原始审计目录 `logs/manual-oneepoch-status-20260920T025811Z/`。原协议、源码快照、失败记录及模型均保留。

## 2. 两个问题分开处理

当前索引器可写为：

\[
z_{hb}=q_h^\top k_b,\quad s_b=\alpha\sum_h\operatorname{ReLU}(z_{hb}),\quad
S=\operatorname{stopgrad}(\operatorname{TopK}(s)),\quad r_b=\operatorname{softmax}_{b\in S}(s_b/\tau).
\]

教师 T 是当前稀疏主注意力在所选支持上的 block-max 分布，停止梯度。忽略批次归一化，在正常归一化教师下：

\[
\frac{\partial L_{KL}}{\partial z_{hb}}
=\frac{\alpha}{\tau}(r_b-T_b)\mathbf{1}[b\in S]\mathbf{1}[z_{hb}>0].
\]

因此至少有两个不同问题：

1. **负值区没有梯度。**一个 query 的所有相关点积非正时，ReLU 使这条 query 的直接索引器梯度为零。共享参数、其他 query、Adam 动量和变化的主干仍可能使它恢复，不能叫永久失活。
2. **未选块缺少直接纠错信号。**当前 KL 只约束已经选中的块；KL 小，不代表没有漏掉重要块。

先研究第一项。不要同时改激活、监督范围、学习率和选块规则后，将全部效果归给一种机制。向分数统一加正常数不解决 ReLU 负区梯度；随机打破平分也不等于恢复学习。

## 3. 阶段 A：复用模型，先确认改路由是否值得

### A1. 先补基础质量，再作诊断

- 核验最终 checkpoint 的前向重放和当前实现与原文的对应，补 D/E 固定完整 dev 的 LM NLL/PPL，按来源及位置报告；不在这里挑最佳 checkpoint。
- 此完整 dev 一旦用于选择方案，就作为开发证据，不能再冒充未接触的最终测试。后续语言任务及确认集的数据、评分、非劣标准须在看结果前固定。
- 诊断使用既有 48 窗面板及从训练集按固定 hash 抽出的少量校准窗口。校准窗口不得流入独立质量确认集。
- 使用已有 1M 词、5M 词和最终快照；初始化点需要按固定 seed 重建。model-only 快照不作为带 optimizer 的断点恢复点。

### A2. 记录能区分原因的量

按三个 global 层、query 位置和有效候选块数分桶记录：ReLU 前点积分布、所有候选均非正比例、打分跨度、学生/教师熵、索引器参数与 RMS 增益、梯度与参数更新比例、选块变化率、与 prefix/local 的重合度。

零分比例重点报告在“超过 64 个完整块”的查询上，并分别说明是否计入无 LM 目标的最后位置。更换激活后不能仅以“零分消失”宣布成功，因为这可能只是定义导致。

同时计算**同一模型、同一层输入下，所选块保留的完整因果注意力概率质量**：用该层原始 q/k 的全支持 softmax，累计被保留 token 的概率之和，包含相同尾块。不能用只在所选块归一化的教师算覆盖率，那会接近恒为 1；不能将 block-max 当概率质量。完整概率质量只是诊断参考，不保证最优语言预测。

### A3. 固定权重的选块干预

在固定诊断窗口上，比较 learned、最早 64 完整块、最近 64 完整块、固定随机 64 完整块；候选不足时全部保留，尾块与因果规则完全相同。记录 NLL 与覆盖率。

覆盖率在同一层输入上比较；改变掩码后的整模型 NLL 是另一项干预，不能说其所有层输入仍相同。冻结模型临时换 mask 有分布变化，因此不能取代后面的从头训练 W 对照。完整注意力选块 oracle 如运行，只作有额外信息的诊断参考，不作为可部署方法。

**决策：**若路由改变明显影响预测且原 learned 退化，进入索引器优化。若各种路由都差不多，优先跑 W 判断当前任务是否根本不需要学习式路由，不继续用这批数据追逐零分指标。

## 4. 阶段 B：先测简单优化，再测非零负区梯度

### B1. 廉价的索引器局部实验

冻结从已有模型提取的隐藏特征、所选支持和教师，固定初始化、样本顺序、200 次 router-only 更新，做一个 2×2 诊断：

| 条件 | 峰值索引器 LR | 分数尺度 |
|---|---:|---:|
| 原设置 | 1e-3 | 1 |
| 只降 LR | 1e-4 | 1 |
| 只改尺度 | 1e-3 | 1/sqrt(128) |
| 联合作为交互诊断 | 1e-4 | 1/sqrt(128) |

固定支持/教师是为隔离梯度动力学；它不等于完整训练算法，也不复现移动主干和动态 topK。工程/诊断更新单独记账。记录保留校准特征上的指标，不仅看拟合过的特征。

原 QSA 公式没有显式 1/sqrt(d)；尺度 1 不能直接判为实现错误。正的统一尺度不改变固定权重的 topK 排名，但改变 KL 温度及后续优化。索引器 LR 1e-3 是否过大也须由更新比例及干预结果判断，不能只和主干 LR 比大小。降低辅助损失权重不等价于在 Adam 下同比降低 LR。

### B2. 最多三个完整模型短试验

全部从随机初始化、第一步稀疏开始，各最多 500 更新，采用原 1413 步一轮调度的前缀，不能将 500 步当新终点重新快速退火。主干 LR、数据顺序、批量、初始化、裁剪、稀疏预算保持原样。

- **首选简单配方候选：仅降索引器 LR 到 1e-4。**检验较小步长是否避免快速进入零梯度区。
- **尺度候选：仅改 score scale。**仅在 A/B1 显示温度/饱和问题时运行，保持其他变量不变。
- **激活候选：仅将 ReLU 换为 LeakyReLU，负斜率固定 0.01。**当配方修正仍不能避免负区问题时运行，不再搜索斜率。与原配置比较先单独改这一项；若以后组合降 LR，须另设消融，不能混为单因素证据。

LeakyReLU 的负区导数非零，使该区仍可接收误差信号，但不能保证优化稳定、正确排序或更低 PPL。它是已有技术，不直接称为新方法。保留原 KL、top64 与尾块规则；不同时加入全支持教师或探索块。

短试验属于探索。先看有效查询的分数/梯度/覆盖是否改善，再看固定面板与训练损失是否相应改善。最多选一个最小改动候选进入完整训练，不根据单个最优点挑 checkpoint。

## 5. 阶段 C：一轮完整对照，检验改进是否有价值

| 组 | 作用 | 本轮安排 |
|---|---|---|
| D：全程密集 | 质量参考 | 原始配对 seed 的已有一轮结果可复用 |
| E：原始 step0 稀疏 | 原方法参考 | 原始配对 seed 的已有一轮结果可复用 |
| F：最小有效改动，step0 稀疏 | 核心候选 | 全新初始化，完整一轮 |
| W：固定最近 64 完整块＋相同尾块 | 检验学习式选块是否必要 | 全新初始化，完整一轮，无索引器 |
| L：短密集预热后稀疏 | 已知有效思路的强对照 | 有质量信号后运行完整一轮 |

L 暂定前 1M 词密集主注意力并训练索引器，其后稀疏；这 1M 词包含在同一轮总量内，不额外重复数据。密集阶段的全支持教师计算、词暴露和时间均计入成本。L 使用与 F 对应的合理索引器配方，以免拿优化后的 F 对比明显欠优化的 L；F/L 用来比较是否需要密集预热。它是受前人启发的适配对照，不冒充原论文复现。若最终要区分原配方 E/L 的纯调度效应，必须单独配对，不混用超参。

所有组仍固定 22,598 窗口、1413 更新、同一轮输入和监督 token；共同主干峰值 LR 3e-4、1M 词 warmup、cosine 到 3e-5、AdamW 和独立裁剪等延用已冻结配方。新组先冻结配置及源码 hash。W 参数/索引开销更少，这是它的实际优势，不人为补无用计算。

主指标保持末 100 更新 1314–1413 的 token 加权纯 LM NLL 与 exp(NLL)，同时保留逐步 loss/PPL 均值；辅助 KL 独立报告。另评固定最终 checkpoint 的完整 dev、来源/位置差异和预先冻结语言任务。若使用标准任务，采用其官方协议；不把自行生成检索题当语言能力主证据。

**停止或调整标准：**

- 零分减少而覆盖、语言质量不改善：不能声称修复了冷启动质量问题。
- W 与 F 相当且成本更低：当前设置没有证明学习式索引器的必要性，应报告该结果；先验证自然长依赖数据的必要性，再考虑扩大。
- 只有 L 有效：说明这一设置支持预热方案，step0 改进目标尚未达成。
- F 接近 D 且超过原 E：只是候选成立；不要求 F 反超 D，也不直接宣布论文成立。

## 6. 阶段 D：独立确认和真实成本，后置且有条件

有可解释的候选后，冻结全部超参、主要比较和语言任务。新增两个独立配对 seed 做初步稳定性检查；探索 seed 与确认 seed 分开呈现，不能把事后选择的探索 seed 当独立确认。两次确认仍可能统计功效不足，追加由观察方差和费用决定，不能默认“3 seed 就够论文”。

质量非劣的建议规划目标是：固定主要语言建模评测上 PPL 增幅不超过 1%（NLL 界限 log(1.01)），并报告任务质量；这是待冻结的工程容忍度，不是从现有 1.762% 倒推的成功阈值，也不是行业公认标准。确认前说明其实际意义，不能看完确认结果再放宽。使用配对训练重复估计运行间波动；按真实文档/来源聚类的区间只反映评测采样不确定性，不能替代 seed。在线末 100 步不是 100 个独立实验。

当前 reference 仍分配完整分数矩阵，E 慢约 4%；质量探索期间不宣称省钱。只有候选有质量价值后，才实现实际跳过未选块的前向/反向，并与参考检查输出和梯度。在同一 GPU、dtype、批量和长度上，与合理优化的 dense SDPA/Flash 实现比较，计入索引器、排序、辅助目标、反向、optimizer、编译、数据和保存；同时报告训练核心时间与整体用时。

先 profile 2K 下三个 global 层占比，评估可节约时间上限。若上限太小，不长时间打磨内核。4K/8K 扩展必须选真实长文档并审计文档边界，不能把拼接无关短句或填充当长距离建模证据。新数据、token 暴露和模型规模关系另行冻结，不能偷换成本口径。

“质量接近”可接受；但实际成本改善必须被测到。记录节省幅度和不确定性，不把理论连接数减少当端到端收益。

## 8. 相关工作与贡献边界

- [Qwen3.8-Next 技术报告，QSA §2.1.2](https://arxiv.org/html/2608.30320v1#S2.SS1.SSS2)：已有主干上的 indexer warmup 与后续稀疏适配不是从随机初始化第一步稀疏的直接结论。报告公式使用多头 ReLU 聚合，不能自行将未缩放判为 bug。本项目不称完整 Qwen4 复现。
- [MiniMax Sparse Attention，附录 B.4/B.6](https://arxiv.org/html/2606.13392v1#A2.SS4)：已讨论早期随机路由、主注意力变化和预热作用，也做局部窗口对照。因此“加预热”“补 W”“测覆盖率”是必要对照，不能直接包装为新贡献。
- [DeepSeek-V3.2 §2.1](https://arxiv.org/html/2512.02556v1#S2.SS1)：dense warmup 与 sparse 阶段设置、加权多头 indexer 和 QSA 不完全相同；不能将其 warmup 学习率或缩放机械移植后宣称修复原文。
- [Dying ReLU and Initialization](https://arxiv.org/abs/1903.06733)：ReLU 失活与激活修正已有研究基础。简单更换激活或降低 LR 本身不足以成为论文贡献。

目前可研究的贡献候选是：识别并定量解释所测原生稀疏训练中的路由退化，区分优化配方、激活梯度和选择监督盲区，证明一个低开销的 step0 方案在独立设置中减少密集预热需求，并保留质量及实际成本优势。只有实验链成立、针对最终方法查清直接重合后，才使用这个表述；若只得到配方修正，就按配方修正报告。
